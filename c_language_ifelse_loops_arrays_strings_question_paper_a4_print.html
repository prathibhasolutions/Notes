Section A: Multiple Choice Questions (10 x 1 = 10 Marks)

  1. Which condition correctly checks whether a year y is a leap year in C? A) y % 4 == 0 || y % 100 != 0 B) (y % 400 == 0) || (y % 4 == 0 && y % 100 != 0) C) y % 100 == 0 && y % 4 == 0 D) y % 4 == 0 && y % 400 != 0
  2. For int n = 29, what is the smallest valid divisor check limit in prime testing loop for efficiency? A) n - 1 B) n / 2 C) sqrt(n) D) n
  3. Which loop always executes at least once? A) for B) while C) do-while D) nested for
  4. In nested loops for a right triangle star pattern of n rows, number of stars in row i is: A) n B) i C) n - i D) 2i - 1 in all cases
  5. What is the valid declaration of a 2D integer array with 3 rows and 4 columns? A) int a(3,4); B) int a[3][4]; C) int a{3}{4}; D) int[3][4] a;
  6. Which function is used to find length of a string in C? A) len() B) strlen() C) strsize() D) length()
  7. What is the output of strcmp("cat", "cat")? A) 0 B) Positive value C) Negative value D) Compilation error
  8. Which if-else ladder order is best for grading marks to avoid wrong classification? A) ascending thresholds B) random order C) descending thresholds D) only single if
  9. If char s[] = "HELLO";, what is s[5]? A) 'O' B) '\\0' C) '\\n' D) Undefined always
  10. Which statement is true for break inside inner loop of nested loops? A) exits both loops B) exits only inner loop C) exits only outer loop D) skips next outer iteration

Section C: Programs (Attempt Any 6 out of 7, 6 x 5 = 30 Marks)

Write complete C programs with proper input, processing, and output formatting. Include suitable conditions and loop logic for edge cases.

  1. Write a program to read basic salary and years of service. Compute bonus using slabs: if service >= 10 and salary <= 30000, bonus is 20%; if service >= 10 and salary > 30000, bonus is 15%; if service between 5 and 9 years, bonus is 10%; otherwise 5%. Print net salary. Sample Input: 28000 12
    Sample Output: Bonus = 5600.00, Net Salary = 33600.00
  2. Write a program to read three side lengths and determine whether the triangle is valid. If valid, classify as Equilateral, Isosceles, or Scalene. Sample Input: 3 4 5
    Sample Output: Valid Triangle, Scalene
  3. Write a program to check whether a number is prime. If it is not prime, print its smallest divisor greater than 1. Sample Input: 91
    Sample Output: Not Prime, Smallest Divisor = 7
  4. Write a program to print all prime numbers between two given integers m and n (inclusive) and also print the count of primes found. Sample Input: 10 25
    Sample Output: 11 13 17 19 23, Count = 5
  5. Nested Loops (Star Pattern): Write a program to print an inverted star pattern where each next row has one less star and one extra leading space. Sample Input: 3
    Sample Output:
    ***
    **
    *
  6. Arrays (1D and 2D): (a) Read n elements into a 1D array and print the second largest distinct element. (b) Read a 3x3 matrix and print sum of principal diagonal. Sample Input: n=6, arr: 5 2 9 9 7 3; matrix: 1 2 3 / 4 5 6 / 7 8 9
    Sample Output: Second Largest Distinct = 7, Principal Diagonal Sum = 15
  7. Write a program to read a sentence and count the number of vowels, consonants. Sample Input: C Language
    Sample Output: Vowels = 4, Consonants = 5
