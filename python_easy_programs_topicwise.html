28) Factorial Function

Write a function to find factorial.

def factorial(n):
    fact = 1
    for i in range(1, n+1):
        fact *= i
    return fact

print("5! =", factorial(5))
print("3! =", factorial(3))

Output: 5! = 120 / 3! = 6
