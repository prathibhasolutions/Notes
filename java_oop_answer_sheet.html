1. Class and Object Basics

Question 1
Create a class Student with fields name, rollNo, and marks.
class Student {
    String name;
    int rollNo;
    double marks;

    void display() {
        System.out.println(name + " " + rollNo + " " + marks);
    }
}
This model answer shows the object state and the method used to print it.
Question 2
Create two Student objects and display their details using a method.
public class Main {
    public static void main(String[] args) {
        Student s1 = new Student();
        Student s2 = new Student();

        s1.name = "Asha";
        s1.rollNo = 10;
        s1.marks = 89.5;

        s2.name = "Ravi";
        s2.rollNo = 11;
        s2.marks = 91.0;

        s1.display();
        s2.display();
    }
}
Two separate objects can hold different data because each instance has its own attribute values.
Question 3
Write a Car class with attributes like brand, model, and speed.
class Car {
    String brand;
    String model;
    int speed;

    void showDetails() {
        System.out.println(brand + " " + model + " " + speed);
    }
}
A class can represent a real-world object with its own data fields and behavior.
Question 4
Create a Book class with title, author, and price, and print the details.
class Book {
    String title;
    String author;
    double price;

    void printBook() {
        System.out.println(title + " by " + author + " - Rs. " + price);
    }
}
This shows how a simple class can model a book's attributes and print them as a summary.

2. Constructors in Java

Question 1
Design a class Employee with a parameterized constructor.
class Employee {
    String name;
    int id;

    Employee(String name, int id) {
        this.name = name;
        this.id = id;
    }

    void display() {
        System.out.println(name + " " + id);
    }
}
The constructor initializes the object immediately with the supplied values.
Question 2
Create a Rectangle class using a constructor to initialize length and breadth.
class Rectangle {
    int length, breadth;

    Rectangle(int length, int breadth) {
        this.length = length;
        this.breadth = breadth;
    }

    int area() {
        return length * breadth;
    }
}
Constructor parameters help set the object state as soon as the instance is created.
Question 3
Write a class where each object stores a unique ID using constructor logic.
class Product {
    static int nextId = 1;
    int id;

    Product() {
        id = nextId++;
    }
}
A static counter can generate unique IDs for every object created.
Question 4
Create a BankAccount class that initializes account number and balance in the constructor.
class BankAccount {
    int accNo;
    double balance;

    BankAccount(int accNo, double balance) {
        this.accNo = accNo;
        this.balance = balance;
    }
}
This is a simple constructor-based initialization pattern used in realistic banking programs.

3. Methods and Behavior

Question 1
Create a Circle class with methods to compute area and circumference.
class Circle {
    double radius;

    double area() {
        return 3.14 * radius * radius;
    }

    double circumference() {
        return 2 * 3.14 * radius;
    }
}
Methods define behavior, while the field stores the object data needed for computation.
Question 2
Write a Calculator class with methods for add(), subtract(), multiply(), and divide().
class Calculator {
    int add(int a, int b) { return a + b; }
    int subtract(int a, int b) { return a - b; }
    int multiply(int a, int b) { return a * b; }
    int divide(int a, int b) { return a / b; }
}
Multiple methods provide different operations without changing the class design.
Question 3
Build a Person class with methods like eat(), sleep(), and study().
class Person {
    void eat() { System.out.println("Eating"); }
    void sleep() { System.out.println("Sleeping"); }
    void study() { System.out.println("Studying"); }
}
This demonstrates a class showing real-world behavior through methods.
Question 4
Create a LibraryBook class with methods to borrow and return the book.
class LibraryBook {
    String title;
    boolean issued;

    void borrow() { issued = true; }
    void returnBook() { issued = false; }
}
Methods can update object state, which is a major part of OOP problem solving.

4. Instance Variables and Static Members

Question 1
Create a class where a static variable counts the number of objects created.
class Student {
    static int count = 0;
    Student() { count++; }
}
The shared count value belongs to the class rather than to any single object.
Question 2
Use both instance and static variables in a class and explain the difference.
class Counter {
    int instanceValue = 5;
    static int staticValue = 10;
}
An instance variable is unique to one object, whereas a static variable is shared across all objects.
Question 3
Create a Department class with a static department name and instance-specific details.
class Department {
    static String deptName = "Computer Science";
    String head;
    int strength;
}
A department name is common to all department objects, while the head and strength differ per object.
Question 4
Write a program to show how a static method can be called without creating an object.

    static void printMessage() {
        System.out.println("Hello");
    }
}
Static methods can be invoked through the class name itself.

5. Encapsulation in Java

Question 1
Implement a Student class with private data members and getter/setter methods.
class Student {
    private String name;
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}
Private fields restrict direct access and keep the data safe.
Question 2
Write a BankAccount class that restricts direct modification of the balance.
class BankAccount {
    private double balance;
    public void deposit(double amount) { balance += amount; }
    public double getBalance() { return balance; }
}
Only controlled methods can alter the balance, which is the main purpose of encapsulation.
Question 3
Use private methods and public methods to show controlled access in a class.
class Example {
    private void helper() { System.out.println("Internal"); }
    public void run() { helper(); }
}
Public methods act as entry points, while private methods handle internal logic.
Question 4
Demonstrate the use of access modifiers like public, private, and protected.
class Demo {
    public int a;
    private int b;
    protected int c;
}
These modifiers define how visible and accessible a member is across the program.

6. Inheritance

Question 1
Create a base class Animal and derived classes Dog and Cat.
class Animal { void sound() { System.out.println("Animal sound"); } }
class Dog extends Animal { void sound() { System.out.println("Bark"); } }
class Cat extends Animal { void sound() { System.out.println("Meow"); } }
Child classes inherit common properties and behavior from the parent class.
Question 2
Write a Vehicle base class and derive Bike and Car.
class Vehicle { String type; }
class Bike extends Vehicle { }
class Car extends Vehicle { }
Inheritance is a clean way to reuse shared features among related classes.
Question 3
Make a Person parent class and Student child class.
class Person { String name; }
class Student extends Person { int rollNo; }
The child class adds its own data while inheriting the parent's data and behavior.
Question 4
Implement a Shape base class with Rectangle and Circle derived classes.
class Shape { double area() { return 0; } }
class Rectangle extends Shape { double length, breadth; }
class Circle extends Shape { double radius; }
Inheritance allows specialized subclasses to extend a shared abstraction.

7. Method Overriding and super()

Question 1
Create a base class Animal with a method sound() and override it in child classes.
class Animal { void sound() { System.out.println("Animal"); } }
class Dog extends Animal { @Override void sound() { System.out.println("Bark"); } }
Overriding changes the method implementation in the subclass.
Question 2
Use super() in a child constructor to call the parent constructor.
class Person { Person(String name) { System.out.println(name); } }
class Student extends Person { Student(String name) { super(name); } }
The child constructor uses super() to initialize parent fields or behavior.
Question 3
Write a parent class Employee and child class Manager using method overriding.
class Employee { void work() { System.out.println("Working"); } }
class Manager extends Employee { @Override void work() { System.out.println("Managing"); } }
This demonstrates specialized subclass behavior while retaining the parent interface.
Question 4
Build a program where a child class changes the behavior of a parent method.
class Shape { void draw() { System.out.println("Shape"); } }
class Rectangle extends Shape { @Override void draw() { System.out.println("Rectangle"); } }
This is a textbook example of how polymorphism and overriding work together in Java.

8. Abstract Classes and Interfaces

Question 1

Abstract classes define a shared contract that subclasses must fulfill.
Question 2

Interfaces describe behavior without providing implementation details.
Question 3
Write a program showing how one class can implement multiple interfaces.
interface A { void a(); }
interface B { void b(); }
class C implements A, B { public void a() {} public void b() {} }
Java allows a class to implement more than one interface, helping in flexible design.
Question 4
Build an example where an abstract class is used as a common base for multiple types.
abstract class Vehicle { abstract void start(); }
class Bike extends Vehicle { public void start() { } }
class Car extends Vehicle { public void start() { } }
An abstract base class ensures a common method signature across diverse related classes.

Question 1

Question 2

A common parent type can work with different subclasses through polymorphism.
Question 3

System.out.println(s.area());
Java decides the overridden method to call at runtime based on the actual object reference.
Question 4

class UpiPayment implements Payment { public void pay() { } }
Interface references let the same code work across different concrete implementations.

18. Threads and Multithreading in Java

Question 1
Create a class that extends Thread and prints numbers from 1 to 10.
class MyThread extends Thread {
    public void run() {
        for (int i = 1; i <= 10; i++) System.out.println(i);
    }
}
This shows the simplest way to create a thread in Java.
Question 2
Write a class that implements Runnable and runs it using a Thread object.
class Task implements Runnable { public void run() { } }
Thread t = new Thread(new Task());
The Runnable interface is often preferred when class reuse is important.
Question 3
Develop a program where two threads execute concurrently and print alternating values.
class PrintTask implements Runnable { public void run() { for (int i = 0; i < 5; i++) System.out.println(i); } }
Concurrent threads help explain shared CPU scheduling and execution overlap.
Question 4
Demonstrate thread synchronization using the synchronized keyword.
synchronized void print() { System.out.println("Safe shared output"); }
Synchronization prevents multiple threads from corrupting shared resource access.
