Module 1Fundamentals of Computers

1.1  Introduction to Computers

1.1.1  What is a Computer?

A computer is an electronic device that accepts data as input, processes it according to a set of instructions (program), and produces information as output. The term "computer" is derived from the Latin word "computare" which means to calculate.

Key Characteristics of Computers:

  • Speed: Computers can process millions of instructions per second
  • Accuracy: Computers perform calculations with near-perfect accuracy
  • Storage: Large amounts of data can be stored and retrieved quickly
  • Automation: Can perform tasks automatically without human intervention
  • Versatility: Can perform various types of tasks
  • Diligence: Can work continuously without fatigue

1.1.2  History of Computers

Generations of Computers:

  1. First Generation (1940-1956): Vacuum Tubes
    • Technology: Vacuum tubes for circuitry, magnetic drums for memory
    • Examples: ENIAC, UNIVAC, EDVAC
    • Characteristics: Very large in size, consumed lot of electricity, generated excessive heat, slow in speed, less reliable
  2. Second Generation (1956-1963): Transistors
    • Technology: Transistors replaced vacuum tubes
    • Examples: IBM 1401, CDC 1604
    • Characteristics: Smaller, faster, more reliable, less heat generation, less power consumption
    • Programming: Assembly language, high-level languages like COBOL, FORTRAN
  3. Third Generation (1964-1971): Integrated Circuits
    • Technology: Integrated Circuits (ICs) - transistors on silicon chips
    • Examples: IBM 360 series, Honeywell-6000 series
    • Characteristics: Smaller size, faster, more reliable, affordable, commercial production started
    • Development: Operating systems, multiprogramming
  4. Fourth Generation (1971-Present): Microprocessors
    • Technology: VLSI (Very Large Scale Integration) - thousands of ICs on single chip
    • Examples: IBM PC, Apple Macintosh, modern desktop computers
    • Characteristics: Portable, reliable, cheap, general-purpose
    • Development: GUI, internet, multimedia
  5. Fifth Generation (Present-Future): Artificial Intelligence
    • Technology: ULSI (Ultra Large Scale Integration), AI, parallel processing
    • Focus: Voice recognition, natural language processing, expert systems
    • Examples: AI systems, quantum computers (in development)

1.1.5  IPO Cycle and Applications of Computers

Every computer works on the same three-step cycle, called the IPO cycle:

  1. Input: Data is entered using input devices such as keyboard, mouse or scanner
  2. Process: The CPU processes the data according to the given instructions
  3. Output: The result is displayed using output devices such as monitor or printer

Example: Typing 10 + 20 in a calculator. The numbers are input using the keypad, the addition is processed by the calculator chip, and the answer 30 is the output shown on the display.

1.4  Computer Memory

1.4.1  Memory Hierarchy

Computer memory is organized in a hierarchy based on speed, cost, and capacity.

Primary Memory (Main Memory):

  1. RAM (Random Access Memory)
    • Volatile memory - loses data when power is off
    • Faster access speed
    • Used for storing currently running programs and data
    • Types: DRAM (Dynamic RAM), SRAM (Static RAM), DDR RAM
    • Capacity: Typically 4GB to 32GB in modern computers
  2. ROM (Read Only Memory)
    • Non-volatile memory - retains data when power is off
    • Stores permanent instructions (BIOS, firmware)
    • Types: PROM (Programmable), EPROM (Erasable Programmable), EEPROM (Electrically Erasable Programmable)
  3. Cache Memory
    • Very fast memory between CPU and RAM
    • Stores frequently accessed data
    • Levels: L1 (fastest, smallest), L2, L3 (slowest, largest)

Secondary Memory (Storage Devices):

Storage DeviceCharacteristics
Hard Disk Drive (HDD)Magnetic storage, 500GB to 10TB capacity, slower than SSD, cheaper per GB, used for mass storage
Solid State Drive (SSD)Flash memory based, faster than HDD, more expensive, no moving parts, more durable
Optical DiscsCD (700MB), DVD (4.7GB), Blu-ray (25GB), uses laser technology, portable
USB Flash DrivePortable, 4GB to 256GB+, plug and play, uses flash memory

1.5  Number Systems

1.5.1  Types of Number Systems

  1. Decimal Number System (Base 10)
    • Uses digits: 0-9
    • Most commonly used by humans
    • Example: 125, 456, 789
  2. Binary Number System (Base 2)
    • Uses digits: 0, 1
    • Used by computers internally
    • Example: 1010, 1101, 11110
  3. Octal Number System (Base 8)
    • Uses digits: 0-7
    • Used in computer programming
    • Example: 12, 45, 77
  4. Hexadecimal Number System (Base 16)
    • Uses digits: 0-9 and A-F (A=10, B=11, C=12, D=13, E=14, F=15)
    • Used in memory addresses, color codes
    • Example: 1A, FF, A5

1.5.2  Number System Conversions

Decimal to Binary:

  • Divide decimal number by 2
  • Note the remainder
  • Repeat until quotient becomes 0
  • Write remainders in reverse order
  • Example: (25)10 = (11001)2

Binary to Decimal:

  • Multiply each bit by 2position
  • Sum all values
  • Example: (1101)2 = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = (13)10

Decimal to Octal:

  • Divide by 8, note remainders
  • Example: (65)10 = (101)8

Decimal to Hexadecimal:

  • Divide by 16, note remainders
  • Example: (255)10 = (FF)16

1.5.3  Binary to Octal and Octal to Binary

Binary to Octal (group bits in threes from the right):

  • Example: (1101101)2 → group as 001 101 101 → read each group (1, 5, 5) → (155)8

Octal to Binary (replace each digit by 3 bits):

  • Example: (155)8 → 1, 5, 5 → 001 101 101 → (1101101)2

Binary to Hexadecimal and Hexadecimal to Binary:

  • Binary to Hex: group bits in fours from the right and convert each group
  • (1101 1010)2 → 1101 = D, 1010 = A → (DA)16
  • Hex to Binary: D = 1101, A = 1010 → (11011010)2

1.5.4  Codes Used in Computers

1.6  Files, Folders and Data Storage

1.6.1  What is a File and a Folder?

  • File: A collection of related information stored under one name, for example report.docx, marks.xlsx, photo.jpg
  • Folder (Directory): A named place on the disk that holds files and other folders, for example Documents, Pictures
  • Sub-folder: A folder created inside another folder

Path: The complete address of a file, for example C:\Users\Ravi\Documents\report.docx. Here C: is the drive, Users is the first folder, Ravi the next and report.docx the file name.

Wildcard Characters:

  • * (asterisk) - matches any number of characters
  • ? (question mark) - matches exactly one character
  • Example: *.txt matches all text files, Report?.docx matches Report1.docx, Report2.docx

1.7  Operating System Basics

1.7.1  What is an Operating System?

An Operating System (OS) is system software that manages computer hardware and software resources and provides common services for computer programs. It acts as an interface between the user and computer hardware.

Functions of Operating System:

  1. Process Management: Managing running programs
  2. Memory Management: Allocating and deallocating memory
  3. File Management: Organizing files and directories
  4. Device Management: Managing input/output devices
  5. Security: Protecting system from unauthorized access
  6. User Interface: Providing interface for user interaction

1.7.2  Types of Operating Systems

  1. Single User, Single Tasking: MS-DOS
  2. Single User, Multi Tasking: Windows, macOS
  3. Multi User: Unix, Linux
  4. Real Time OS: Used in embedded systems, industrial control
  5. Mobile OS: Android, iOS
  6. Network OS: Windows Server, Linux Server

1.7.5  Role of the Operating System

The operating system is called the master program or the supervisor of the computer. It performs the following jobs:

  1. Process Management: Decides which program runs first and manages the programs in the CPU
  2. Memory Management: Allocates memory to programs and takes it back when a program closes
  3. File Management: Creates, names, stores, retrieves and deletes files
  4. Device Management: Installs and operates hardware through device drivers
  5. Security: Uses a login password and permissions to protect the system
  6. User Interface: Provides the desktop, icons and windows that the user works with
  7. Bootstrapping: Loads the operating system into memory at the time of startup

1.8  Computer Languages and Viruses

1.8.1  Computer Language

A computer understands only machine code (binary). A computer language is used to write instructions in a form the computer can process. Every program is finally converted into machine code (0s and 1s).

TypeDescription and Example
Machine LanguageBinary code consisting of 0s and 1s. Directly understood by the CPU but very difficult for humans to write. Example: 10101010
Assembly LanguageUses mnemonics such as ADD, MOV, SUB in place of binary. Needs an assembler. Example: MOV AX, 5
High Level LanguageClose to human language, easy to read and write. Needs a compiler or interpreter. Examples: C, C++, Java, Python, BASIC
Fourth Generation LanguageNon-procedural, user gives only what is required. Examples: SQL, Oracle reports, Visual Basic
Fifth Generation LanguageUsed in artificial intelligence and expert systems. Examples: Prolog, LISP

1.8.2  Language Translators

TranslatorFunction
CompilerTranslates the whole program at once into machine code and produces an object file. Faster at execution. Example: C, C++, Java
InterpreterTranslates and executes line by line. Easier to debug but slower. Example: BASIC, Python, JavaScript
AssemblerConverts assembly language into machine code.
Remember: Compiler = whole program, produces object file, faster. Interpreter = line by line, no object file, slower but simpler.

1.8.3  Computer Viruses and Protection

A computer virus is a malicious program that attaches itself to a program and spreads from one computer to another without the user's knowledge.

Types of Viruses:

  • Boot Sector Virus: Damages the boot sector of the disk
  • File Infector Virus: Infects program files such as .exe and .com
  • Macro Virus: Spreads through macros in Word documents or Excel sheets
  • Worm Virus: Spreads through the network and email on its own
  • Trojan: Looks harmless but performs a hidden harmful action
  • Spyware: Secretly collects information about the user

Symptoms of Virus Infection:

  • Computer becomes very slow without reason
  • System restarts or shuts down by itself
  • Unknown error messages appear
  • Files get corrupted or disappear
  • Disk space reduces suddenly
  • Unwanted pop-up advertisements

Prevention and Removal:

  • Install a good antivirus program and update it regularly
  • Do not open unknown email attachments
  • Scan pen drives before opening files
  • Avoid pirated software and cracked games
  • Take regular backup of important data
  • Keep the operating system updated

Types of Network by Arrangement:

Advantages of Computer Networks:

  • Resource and data sharing (files, printers, internet)
  • Fast communication through email and messaging
  • Centralised storage and backup
  • Work can be done from any location

Types of Network Topologies:

TopologyShape and Feature

RingComputers form a closed loop and data moves in one direction only.
MeshEach computer connects to every other computer. Most reliable but very costly.

    • Mobile Data: 3G, 4G, 5G cellular networks
    • Satellite: Internet via satellite, for remote areas

Who is called the father of the computer?Charles Babbage, who designed the Analytical Engine.
What is the full form of RAM and ROM?Random Access Memory and Read Only Memory.
What is cache memory?Very fast memory placed between the CPU and RAM to hold frequently used data.
What is the difference between a cold boot and a warm boot?Cold boot starts from a fully switched-off state; warm boot restarts a computer that is already on.
What is an UPS?Uninterruptible Power Supply; it keeps the computer running during a power failure.
What is a compiler and an interpreter?A compiler translates the whole program at once; an interpreter translates line by line.
What is a modem?Modulator-Demodulator; it converts digital signals into analog signals and back.
What is the use of the Recycle Bin?It stores deleted files so that they can be restored until the bin is emptied.
What is the use of the F4 key in Excel?It toggles a cell reference between relative and absolute, for example A1 to $A$1.
What is AutoFilter?A feature that adds dropdown buttons to a heading row so only the chosen records are shown.
What does the name box in Excel show?The address of the active cell, for example B7.
Which key is used to start a new line inside a cell in Excel?Alt + Enter.
What is a slide thumbnail pane?The panel on the left that shows every slide of the presentation as a small image.
What is Presenter View?A slide show view where the presenter sees notes, a timer and the next slide on their own screen.
What is the full form of HTTP?HyperText Transfer Protocol.
What is a cookie?A small text file a website stores in the browser to remember the user.
What is the difference between Cc and Bcc in email?Cc recipients are visible to everyone; Bcc recipients stay hidden.
