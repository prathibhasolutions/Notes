Module 1Fundamentals of Computers

1.1  Introduction to Computers

1.1.1  What is a Computer?

A computer is an electronic device that accepts data as input, processes it according to a set of instructions (program), and produces information as output. The term "computer" is derived from the Latin word "computare" which means to calculate.

Key Characteristics of Computers:

  • Speed: Computers can process millions of instructions per second
  • Accuracy: Computers perform calculations with near-perfect accuracy
  • Storage: Large amounts of data can be stored and retrieved quickly
  • Automation: Can perform tasks automatically without human intervention
  • Versatility: Can perform various types of tasks
  • Diligence: Can work continuously without fatigue

1.1.2  History of Computers

Generations of Computers:

  1. First Generation (1940-1956): Vacuum Tubes
    • Technology: Vacuum tubes for circuitry, magnetic drums for memory
    • Examples: ENIAC, UNIVAC, EDVAC
    • Characteristics: Very large in size, consumed lot of electricity, generated excessive heat, slow in speed, less reliable
  2. Second Generation (1956-1963): Transistors
    • Technology: Transistors replaced vacuum tubes
    • Examples: IBM 1401, CDC 1604
    • Characteristics: Smaller, faster, more reliable, less heat generation, less power consumption
    • Programming: Assembly language, high-level languages like COBOL, FORTRAN
  3. Third Generation (1964-1971): Integrated Circuits
    • Technology: Integrated Circuits (ICs) - transistors on silicon chips
    • Examples: IBM 360 series, Honeywell-6000 series
    • Characteristics: Smaller size, faster, more reliable, affordable, commercial production started
    • Development: Operating systems, multiprogramming
  4. Fourth Generation (1971-Present): Microprocessors
    • Technology: VLSI (Very Large Scale Integration) - thousands of ICs on single chip
    • Examples: IBM PC, Apple Macintosh, modern desktop computers
    • Characteristics: Portable, reliable, cheap, general-purpose
    • Development: GUI, internet, multimedia
  5. Fifth Generation (Present-Future): Artificial Intelligence
    • Technology: ULSI (Ultra Large Scale Integration), AI, parallel processing
    • Focus: Voice recognition, natural language processing, expert systems
    • Examples: AI systems, quantum computers (in development)

1.4  Computer Memory

1.4.1  Memory Hierarchy

Computer memory is organized in a hierarchy based on speed, cost, and capacity.

Primary Memory (Main Memory):

  1. RAM (Random Access Memory)
    • Volatile memory - loses data when power is off
    • Faster access speed
    • Used for storing currently running programs and data
    • Types: DRAM (Dynamic RAM), SRAM (Static RAM), DDR RAM
    • Capacity: Typically 4GB to 32GB in modern computers
  2. ROM (Read Only Memory)
    • Non-volatile memory - retains data when power is off
    • Stores permanent instructions (BIOS, firmware)
    • Types: PROM (Programmable), EPROM (Erasable Programmable), EEPROM (Electrically Erasable Programmable)
  3. Cache Memory
    • Very fast memory between CPU and RAM
    • Stores frequently accessed data
    • Levels: L1 (fastest, smallest), L2, L3 (slowest, largest)

Secondary Memory (Storage Devices):

Storage DeviceCharacteristics
Hard Disk Drive (HDD)Magnetic storage, 500GB to 10TB capacity, slower than SSD, cheaper per GB, used for mass storage
Solid State Drive (SSD)Flash memory based, faster than HDD, more expensive, no moving parts, more durable
Optical DiscsCD (700MB), DVD (4.7GB), Blu-ray (25GB), uses laser technology, portable

External HDD/SSDPortable external storage, USB connection, backup purposes

1.4.2  Memory Units

Understanding data measurement units:

  • Bit: Smallest unit (0 or 1)
  • Nibble: 4 bits
  • Byte: 8 bits (can represent one character)
  • Kilobyte (KB): 1024 bytes
  • Megabyte (MB): 1024 KB
  • Gigabyte (GB): 1024 MB
  • Terabyte (TB): 1024 GB
  • Petabyte (PB): 1024 TB

1.5  Number Systems

1.5.1  Types of Number Systems

  1. Decimal Number System (Base 10)
    • Uses digits: 0-9
    • Most commonly used by humans
    • Example: 125, 456, 789
  2. Binary Number System (Base 2)
    • Uses digits: 0, 1
    • Used by computers internally
    • Example: 1010, 1101, 11110
  3. Octal Number System (Base 8)
    • Uses digits: 0-7
    • Used in computer programming
    • Example: 12, 45, 77
  4. Hexadecimal Number System (Base 16)
    • Uses digits: 0-9 and A-F (A=10, B=11, C=12, D=13, E=14, F=15)
    • Used in memory addresses, color codes
    • Example: 1A, FF, A5

1.5.2  Number System Conversions

Decimal to Binary:

  • Divide decimal number by 2
  • Note the remainder
  • Repeat until quotient becomes 0
  • Write remainders in reverse order
  • Example: (25)10 = (11001)2

Binary to Decimal:

  • Multiply each bit by 2position
  • Sum all values
  • Example: (1101)2 = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = (13)10

Decimal to Octal:

  • Divide by 8, note remainders
  • Example: (65)10 = (101)8

Decimal to Hexadecimal:

  • Divide by 16, note remainders
  • Example: (255)10 = (FF)16

1.6  Operating System Basics

1.6.1  What is an Operating System?

An Operating System (OS) is system software that manages computer hardware and software resources and provides common services for computer programs. It acts as an interface between the user and computer hardware.

Functions of Operating System:

  1. Process Management: Managing running programs
  2. Memory Management: Allocating and deallocating memory
  3. File Management: Organizing files and directories
  4. Device Management: Managing input/output devices
  5. Security: Protecting system from unauthorized access
  6. User Interface: Providing interface for user interaction

1.6.2  Types of Operating Systems

  1. Single User, Single Tasking: MS-DOS
  2. Single User, Multi Tasking: Windows, macOS
  3. Multi User: Unix, Linux
  4. Real Time OS: Used in embedded systems, industrial control
  5. Mobile OS: Android, iOS
  6. Network OS: Windows Server, Linux Server

1.6.3  Popular Operating Systems

Windows:

  • Developed by Microsoft
  • User-friendly GUI
  • Versions: Windows 7, 8, 10, 11
  • Widely used for desktop computers

Linux:

  • Open-source OS
  • Free to use and modify
  • Distributions: Ubuntu, Fedora, Debian, CentOS
  • Popular in servers and programming

macOS:

  • Developed by Apple
  • Used in Apple Mac computers
  • Known for design and performance

Mobile Operating Systems:

  • Android: Open-source, Google, most popular mobile OS
  • iOS: Apple, used in iPhone and iPad

File Management:

  2. Absolute Reference: $A$1 (doesn't change when copied)

3.1  Introduction to Internet

3.1.1  What is Internet?

The Internet is a global network of billions of computers and electronic devices connected together. It allows users to access information, communicate, and share data across the world.

Key Features:

  • Global connectivity
  • Information sharing
  • Communication platform
  • Resource sharing
  • 24/7 availability

History of Internet:

  • 1969: ARPANET created (first network)
  • 1983: TCP/IP protocol adopted
  • 1989: Tim Berners-Lee invented World Wide Web (WWW)
  • 1990s: Internet became public and commercial
  • 2000s: Broadband, social media, mobile internet
  • Present: IoT, cloud computing, 5G

3.2  Internet Connectivity

3.2.1  Types of Internet Connections

  1. Dial-Up Connection
    • Uses telephone line and modem
    • Speed: 56 Kbps (very slow)
    • Cannot use phone and internet simultaneously
    • Obsolete technology
  2. Broadband Connection
    • DSL (Digital Subscriber Line): Uses telephone line, faster than dial-up, 1-100 Mbps
    • Cable: Uses cable TV infrastructure, 10-500 Mbps
    • Fiber Optic: Uses fiber optic cables, 100-1000 Mbps (1 Gbps), fastest
  3. Wireless Connection
    • Wi-Fi: Wireless local area network, range 30-50 meters
    • Mobile Data: 3G, 4G, 5G cellular networks
    • Satellite: Internet via satellite, for remote areas

3.2.2  Required Equipment

  • Computer/Device: PC, laptop, smartphone, tablet
  • Modem: Converts digital signals to analog and vice versa
  • Router: Distributes internet connection to multiple devices
  • ISP Account: Subscription from Internet Service Provider
  • Browser: Software to access websites

A web browser is software that allows users to access, retrieve, and display content from the World Wide Web.

3.4  Search Engines

3.4.1  What is a Search Engine?

A search engine is a web-based tool that helps users find information on the internet by searching for keywords or phrases.

Popular Search Engines:

  • Google: Most popular, 90%+ market share
  • Bing: Microsoft's search engine
  • Yahoo: Older search engine, still in use
  • DuckDuckGo: Privacy-focused, no tracking

3.4.2  How to Use Search Engines

Basic Search:

  • Type keywords in search box

  • Browse search results

Search Tips:

  • Use specific keywords
  • Use multiple keywords for better results
  • Check spelling
  • Use quotation marks for exact phrases: "climate change"
  • Use minus sign to exclude words: jaguar -car
  • Use site: to search specific website: site:wikipedia.org python

3.5  Email (Electronic Mail)

3.5.1  Introduction to Email

Email (Electronic Mail) is a method of exchanging messages between people using electronic devices over the internet.

Advantages of Email:

  • Instant delivery
  • Cost-effective (free)
  • 24/7 accessibility
  • Can send to multiple recipients
  • Attach files and documents
  • Maintain record of communication
  • Professional communication

Popular Email Services:

  • Gmail: Google's email service
  • Outlook: Microsoft's email (formerly Hotmail)
  • Yahoo Mail: Yahoo's email service
  • ProtonMail: Encrypted, privacy-focused
  • iCloud Mail: Apple's email service

3.5.2  Email Address Structure

An email address has two parts separated by @ symbol:

Format: username@domain.com

  • Username: Unique identifier (e.g., john.doe, student123)
  • @ Symbol: Separates username and domain
  • Domain: Email service provider (gmail.com, outlook.com)

Examples:

  • john.doe@gmail.com
  • student123@outlook.com
  • contact@prathibhainstitute.com

3.5.3  Creating Email Account

Steps to Create Gmail Account:

  1. Go to www.gmail.com
  2. Click "Create account"
  3. Enter personal information:
    • First name and Last name
    • Choose username (email address)
    • Create strong password
  4. Verify phone number
  5. Add recovery email (optional but recommended)
  6. Enter date of birth and gender
  7. Agree to terms and conditions
  8. Complete verification

Password Guidelines:

  • Minimum 8 characters
  • Mix of uppercase and lowercase letters
  • Include numbers
  • Include special characters (@, #, $, etc.)
  • Don't use personal information
  • Don't use common words

3.5.5  Composing and Sending Email

Steps to Send Email:

  1. Click "Compose" button
  2. Email compose window opens
  3. Fill in details:
    • To: Recipient's email address
    • Cc (Carbon Copy): Send copy to others (everyone sees)
    • Bcc (Blind Carbon Copy): Send copy to others (hidden from other recipients)
    • Subject: Brief description of email
    • Body: Main message content
  4. Format text (bold, italic, underline, font, color)
  5. Attach files if needed
  6. Click "Send"

Email Writing Tips:

  • Clear and descriptive subject line
  • Professional greeting (Dear Sir/Madam, Hi John)

3.6  Internet Security and Safety

3.6.1  Online Threats

  1. Virus: Malicious program that replicates and damages system
  2. Malware: Software designed to harm computer
  3. Phishing: Fake emails/websites to steal information
  4. Spam: Unwanted bulk emails
  5. Ransomware: Locks files and demands payment
  6. Spyware: Secretly monitors user activity
  7. Identity Theft: Stealing personal information
  8. Hacking: Unauthorized access to systems

3.6.2  Security Best Practices

Password Security:

  • Use strong, unique passwords
  • Don't share passwords
  • Change passwords regularly
  • Use password manager
  • Enable two-factor authentication (2FA)

Safe Browsing:

  • Check website security (HTTPS, padlock icon)
  • Don't click suspicious links
  • Avoid downloading from untrusted sites
  • Use secure Wi-Fi networks
  • Clear browser cache and cookies regularly

Email Security:

  • Don't open emails from unknown senders
  • Don't click links in suspicious emails
  • Verify sender before sharing information
  • Don't download unknown attachments
  • Report spam and phishing

Protection Tools:

  • Install antivirus software (Windows Defender, Norton, McAfee)
  • Keep software updated
  • Use firewall
  • Regular system scans
  • Backup important data

Personal Information:

  • Don't share personal details publicly
  • Be cautious on social media
  • Read privacy policies
  • Use privacy settings
  • Monitor bank and credit card statements
