Section B: Theory & Programming Questions (10 x 9 = 90 Marks)

  1. Class and Object: Explain the difference between a class and an object. Write a Python program to create a class Student with attributes name, roll_no, and marks. Create an object and display the student details.
  2. Constructor: What is a constructor in Python? Explain the purpose of __init__(). Write a program to create a class Employee with a constructor that accepts employee name, ID, and salary and displays the details.
  3. Methods: What is a method in Python? Write a class Rectangle with length and width as attributes. Create methods to calculate and display the area and perimeter.
  4. Encapsulation: Explain encapsulation in Python. Write a program to create a class BankAccount with a private variable __balance. Create methods deposit(), withdraw(), and display_balance().
  5. Inheritance: Explain inheritance with an example. Write a Python program with a parent class Animal containing a method eat(). Create a child class Dog that inherits the method and has an additional method bark().
  6. Multiple Inheritance: What is multiple inheritance? Write a Python program with two parent classes Father and Mother. Create a child class Child that inherits from both classes and displays information from both parents.
  7. Polymorphism: Explain polymorphism in Python. Write a program with two classes Circle and Rectangle, each containing an area() method. Create objects of both classes and demonstrate how the same method name performs different operations.
  8. Method Overriding: What is method overriding? Write a Python program with a parent class Vehicle having a method start(). Create child classes Car and Bike and override the start() method in both classes.
  9. super() Method: Explain the purpose of the super() method. Write a Python program with a parent class Person containing a constructor for name and age. Create a child class Student with an additional attribute course. Use super() to call the parent constructor and display all details.
  10. Combined OOP Concepts: Create a Python program for an Employee management system using a class and constructor. Use encapsulation for salary, inheritance for Manager and Developer classes, method overriding for calculating salary, and super() to initialize parent class attributes. Display the details of both employees.
