Section B: Theory & Programming Questions (10 x 9 = 90 Marks)

  1. Classes, Objects, Constructors and Methods: Explain the difference between a class and an object. Explain constructors and methods in Java. Write a Java program to create a class Student with instance variables name, rollNo, and marks. Use a constructor to initialize the values and a method to display the details.
  2. Static and Instance Members: Explain the difference between static and instance variables. Write a Java program to create an Employee class with instance variables name and salary, and a static variable companyName. Create multiple objects and display their details.
  3. Encapsulation: What is encapsulation? Explain access modifiers in Java. Write a Java program to create a BankAccount class with a private balance variable. Create public methods deposit(), withdraw(), and displayBalance() to access and modify the balance.
  4. Inheritance and super(): Explain inheritance in Java. Write a program with a parent class Person containing a constructor and a method display(). Create a child class Student with an additional variable course. Use super() to call the parent constructor and display all details.
  5. Method Overloading and Overriding: Explain the difference between method overloading and method overriding. Write a Java program to demonstrate method overloading using an add() method with different parameter lists. Also create a parent class Animal and child class Dog to demonstrate method overriding.
  6. Polymorphism: Explain compile-time and runtime polymorphism in Java. Write a program using a parent class reference to refer to child class objects and demonstrate runtime polymorphism through method overriding.
  7. Abstraction and Abstract Class: What is abstraction? Explain abstract classes and abstract methods. Create an abstract class Shape with an abstract method area(). Create Circle and Rectangle classes that extend Shape and implement the area() method.
  8. Interfaces: Explain interfaces in Java. Create an interface Printable containing a method printDetails(). Implement the interface in classes Student and Employee and provide their own implementation of the method. Also explain how interfaces support multiple inheritance in Java.
  9. Exception Handling: Explain try, catch, finally, throw, and throws. Write a Java program that accepts two numbers and performs division. Handle ArithmeticException and InputMismatchException using appropriate exception handling. Also demonstrate the use of the finally block.
  10. File Handling and Collections: Write a Java program to create a text file and write student details into it. Read the contents of the file and display them. Then store multiple student names in an ArrayList and display the elements using a loop. Explain the purpose of file handling and collections in Java.
