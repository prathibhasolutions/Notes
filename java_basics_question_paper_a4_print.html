Java Basics - A4 Question Paper
Syllabus: Syntax, Data Types, Variables, Operators, Numbers, Type Casting, Booleans
Time: 90 Minutes
Total Marks: 50
Name: ____________________
Instructions: Answer all questions. Section A has 10 MCQs, Section B has 10 fill in the blanks, and Section C has 6 programs. Program questions must be solved using only the given syllabus and should avoid control structures like if/else and loops.

Section A: Multiple Choice Questions (10 x 1 = 10 Marks)

  1. What is the datatype of the result when an int is added to a double in Java? A) int B) float C) double D) long
  2. Which declaration is valid in Java? A) int a = 10, b = 20; B) int a, b = 10, 20; C) a int = 10; D) int a = b = 10;
  3. What is the value of 5 / 2 + 5 % 2 in Java using int values? A) 1 B) 2 C) 3 D) 4
  4. Which expression uses a bitwise operator? A) a && b B) a & b C) a || b D) !a
  5. If a = 5 and b = 0, what is the result of (a > b) && (b == 0)? A) true B) false C) 0 D) Error
  6. What is the decimal value of binary 101 plus binary 11? A) 6 B) 7 C) 8 D) 9
  7. Which cast is required to assign 19.8 to an int variable? A) (double) B) (float) C) (int) D) No cast needed
  8. What is the output type of the expression 7L + 3? A) int B) long C) float D) byte
  9. Which operator checks value equality for primitive numbers? A) = B) == C) equals D) !=
  10. What is the value of 3 * 2 * 2 + 4 / 2 in Java? A) 10 B) 12 C) 14 D) 16

Section B: Fill In The Blanks (10 x 1 = 10 Marks)

  1. The operator used for remainder in Java is __________.
  2. The datatype used for whole numbers up to about 2 billion is __________.
  3. The datatype suffix used with long literals is __________.
  4. The result type of int / int in Java is generally __________.
  5. Explicit conversion from double to int is called __________.
  6. The boolean datatype in Java is __________.
  7. The operator used for logical AND is __________.
  8. Floor-like integer result of 17 / 3 in int division is __________.
  9. The unary operator used to increase a value by 1 is __________.
  10. The datatype used for decimal values with higher precision than float is __________.

Section C: Programs (6 x 5 = 30 Marks)

Write programs using only syntax, datatypes, variables, operators, numbers, type casting, and booleans. Do not use loops, if/else, arrays, or strings. Keep all programs formula-based and operator-based.

  1. Write a program to read radius and print diameter, circumference, and area of a circle using formulas.
  2. Write a program to read principal, rate, and time, then print simple interest and total amount using formulas.
  3. Write a program to read length, width, and height of a cuboid and print volume and total surface area.
  4. Write a program to read distance (km) and time (hours), then print speed in km/h and m/s.
  5. Write a program to read two numbers and print sum, difference, product, quotient, remainder, and power using operators.
  6. Write a program to read marks of five subjects and print total, average, and percentage using formulas.
