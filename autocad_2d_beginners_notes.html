Part A — AutoCAD Fundamentals

1. What is AutoCAD 2D?

AutoCAD is a computer-aided design (CAD) software used to create precise technical drawings. AutoCAD 2D refers to drafting done on a flat XY plane, used to produce engineering drawings such as machine part drawings (mechanical) and building plans (civil) with exact dimensions, unlike freehand sketching.

  • Every object drawn has exact, measurable coordinates and dimensions.
  • Drawings are created at real-world (1:1) scale and only scaled down when printed.
  • Used across mechanical, civil, electrical, and architectural fields.

2. The AutoCAD Interface

The AutoCAD screen is made up of several key areas that every drafter must recognize before drawing.

  • Drawing Area – the large central space where objects are drawn (the model space).
  • Command Line – a text bar at the bottom where commands are typed and AutoCAD shows prompts.
  • Ribbon / Toolbars – tabs (Home, Insert, Annotate, View) containing icon buttons for commands.
  • UCS Icon – the small arrow icon at the bottom-left showing the current coordinate system (X, Y axes).
  • Status Bar – bottom strip showing coordinates, and toggles for Grid, Snap, Ortho, Osnap, etc.
  • Layout Tabs – at the bottom, switch between Model space and Layout (paper space) sheets.

3. Coordinate Systems

Every point in AutoCAD is placed using one of three coordinate entry methods, typed directly at the command line.

  • Absolute Coordinates – measured from the fixed origin (0,0). Format: X,Y
  • Relative Coordinates – measured from the last point entered. Format: @X,Y
  • Polar Coordinates – distance and angle from the last point. Format: @distance<angle
Command: LINE
Specify first point: 0,0          (absolute - starts at origin)
Specify next point: @50,0         (relative - 50 units right)
Specify next point: @50<90        (polar - 50 units at 90 degrees, i.e. straight up)
Specify next point: @50,50        (relative - diagonal move)
Specify next point: C             (closes the shape back to first point)

4. Units and Drawing Limits (UNITS, LIMITS)

Before drawing, the correct measurement unit and drawing area size must be set up so the drawing is accurate and to scale.

  • UNITS command – sets the type of unit (Decimal, Engineering, Architectural) and the precision (number of decimal places). Mechanical drawings typically use Decimal (mm); Civil drawings often use Architectural (feet-inches) or Decimal (metres).
  • LIMITS command – sets the size of the drawing sheet boundary (lower-left and upper-right corner), used mainly as a plotting reference.
Command: UNITS
(Opens Drawing Units dialog box)
 Type: Decimal
 Precision: 0.00

Command: LIMITS
Specify lower left corner [ON/OFF] <0.0000,0.0000>: 0,0
Specify upper right corner <420.0000,297.0000>: 420,297   (A3 sheet in mm)

5. Layers – Concept and Creation (LAYER)

A layer is like a transparent sheet used to organize objects by type — for example, one layer for outlines, one for dimensions, one for hidden lines, one for centre lines. Every object takes on the colour, linetype, and lineweight of the layer it is placed on unless overridden.

  • Open the Layer Properties Manager by typing LA or LAYER.
  • Click "New Layer", type a name, then set its Colour, Linetype, and Lineweight.
  • Set a layer "Current" before drawing so new objects go onto it.
  • Standard mechanical layers: Outline (continuous, thick), Centre (centre linetype, thin), Hidden (dashed linetype, thin), Dimension (continuous, thin).
  • Standard civil layers: Walls, Doors-Windows, Dimensions, Text, Grid/Axis, Furniture.
Command: LAYER
(Layer Properties Manager opens)
New Layer -> name: OUTLINE   -> Colour: White -> Linetype: Continuous -> Lineweight: 0.50mm
New Layer -> name: CENTRE    -> Colour: Red   -> Linetype: CENTER     -> Lineweight: 0.25mm
New Layer -> name: HIDDEN    -> Colour: Yellow-> Linetype: HIDDEN     -> Lineweight: 0.25mm
New Layer -> name: DIMENSION -> Colour: Green -> Linetype: Continuous -> Lineweight: 0.18mm
Set OUTLINE as current layer before drawing the object outline.

6. Drawing Aids: OSNAP, ORTHO, POLAR, GRID, SNAP

These tools help place points with pixel-perfect accuracy instead of clicking freehand, which is essential for engineering-accurate drawings.

  • OSNAP (Object Snap) – F3 to toggle. Locks the cursor onto exact geometric points: Endpoint, Midpoint, Centre, Intersection, Perpendicular, Tangent, Quadrant, Nearest.
  • ORTHO – F8 to toggle. Restricts the cursor to strictly horizontal or vertical movement.
  • POLAR TRACKING – F10 to toggle. Displays a dotted guide line and angle tooltip when the cursor nears set angles (e.g. 0, 30, 45, 90 degrees).
  • GRID – F7 to toggle. Displays a background dot/line grid as a visual measuring reference (does not print).
  • SNAP – F9 to toggle. Forces the cursor to jump only to fixed grid spacing intervals.
  • Dynamic Input – F12 to toggle. Shows coordinate and length values directly next to the cursor while drawing.
F3 OSNAP F7 GRID F8 ORTHO F9 SNAP F10 POLAR F12 DYNAMIC INPUT

Part B — Draw Commands

7. LINE (Shortcut: L)

Draws one or more straight line segments between points. Each segment is a separate object unless drawn with Polyline.

  • Type LINE or L, press Enter.
  • Click or type the first point.
  • Click or type each next point; AutoCAD keeps drawing connected segments.
  • Press Enter/Esc to stop, or type C to close the shape back to the start point, or U to undo the last segment.
Command: LINE
Specify first point: 0,0
Specify next point: 100,0
Specify next point: 100,60
Specify next point: 0,60
Specify next point: C

8. Construction Line & Ray (XLINE, RAY)

XLINE draws an infinite line in both directions through a point, used as a temporary reference/guide line. RAY draws a line infinite in only one direction. Both are typically drawn on a non-printing "construction" layer and deleted or frozen before final plotting.

  • Type XLINE (or XL); specify a point, then a second point or an angle.
  • Options include Horizontal, Vertical, Angle, Bisect, and Offset.
Command: XLINE
Specify a point or [Hor/Ver/Ang/Bisect/Offset]: H     (creates an infinite horizontal reference line)
Specify through point: 0,50

9. POLYLINE (Shortcut: PL)

Draws connected straight and/or curved segments that behave as a single combined object, unlike LINE where every segment is separate. Widely used for outlines, borders, and shapes that need uniform width.

  • Type PLINE or PL, specify the start point.
  • Type W to set a start/end width if a thick outline is needed.
  • Type A to switch to Arc segment mode, L to switch back to Line mode.
  • Type C to close the polyline into a loop.
Command: PLINE
Specify start point: 0,0
Current line-width is 0.0000
Specify next point: 80,0
Specify next point [Arc/Width]: A
Specify endpoint of arc: 100,20
Specify endpoint of arc [Line]: L
Specify next point: 100,60
Specify next point: C

10. RECTANGLE (Shortcut: REC)

Draws a rectangle as a single polyline object by specifying two diagonally opposite corners. Very commonly used for plot boundaries, room outlines, and part blanks.

  • Type RECTANG or REC.
  • Specify the first corner point.
  • Specify the opposite corner – either by clicking, or typing relative coordinates for exact width/height.
  • Options before the first corner include Chamfer and Fillet, to create rectangles with cut or rounded corners.
Command: RECTANG
Specify first corner point [Chamfer/Fillet]: 0,0
Specify other corner point [Dimensions]: @120,80    (120 wide, 80 tall rectangle)

11. POLYGON

Draws a regular polygon (equal sides and angles), from 3 to 1024 sides, based on the number of sides and either an inscribed/circumscribed circle radius or one edge length.

  • Type POLYGON, enter the number of sides.
  • Specify the centre point of the polygon.
  • Choose I (Inscribed – polygon fits inside an imaginary circle) or C (Circumscribed – polygon fits around an imaginary circle).
  • Enter the radius of that imaginary circle.
Command: POLYGON
Enter number of sides <4>: 6
Specify center of polygon or [Edge]: 60,40
Enter an option [Inscribed in circle/Circumscribed about circle] <I>: I
Specify radius of circle: 25      (draws a regular hexagon - used for bolt heads)

12. CIRCLE (Shortcut: C)

Draws a circle using one of several construction methods depending on what information is known.

  • Centre, Radius – default method: pick centre, type radius.
  • Centre, Diameter – type D after picking centre, then enter diameter.
  • 2-Point (2P) – circle passes through two given points (its diameter endpoints).
  • 3-Point (3P) – circle passes through three given points.
  • Tan, Tan, Radius (TTR) – circle tangent to two existing objects with a given radius.
Command: CIRCLE
Specify center point for circle or [3P/2P/Ttr]: 50,50
Specify radius of circle or [Diameter]: 20

13. ARC (Shortcut: A)

Draws a curved segment that is part of a circle, using various combinations of Start point, Centre, End point, Angle, Direction, Radius, or Chord Length. The most common method is 3-Point.

  • 3-Point – specify a start point, a point on the arc, and an end point.
  • Start, Centre, End – specify start point, then centre, then end angle/point.
  • Start, Centre, Angle – specify start, centre, and an included angle to sweep.
Command: ARC
Specify start point of arc or [Center]: 0,0
Specify second point of arc or [Center/End]: 20,15
Specify end point of arc: 40,0

14. ELLIPSE

Draws an ellipse (or elliptical arc) by defining its axes. Used in mechanical work for representing angled circular holes/features, and in civil work for landscaping/curved features.

  • Type ELLIPSE, specify one endpoint of the first axis, then the other endpoint.
  • Then specify the distance for the second (half) axis, or type C to define by centre first.
Command: ELLIPSE
Specify axis endpoint of ellipse or [Arc/Center]: 0,0
Specify other endpoint of axis: 80,0
Specify distance to other axis or [Rotation]: 30

15. SPLINE

Draws a smooth, flowing curve that passes through (or near) a series of picked points. Used for irregular/free-form boundaries such as contour lines in civil site plans or cam-profile curves in mechanical design.

  • Type SPLINE, pick multiple points along the desired curve path.
  • Press Enter to finish; optionally specify start and end tangent directions.
Command: SPLINE
Specify first point: 0,0
Specify next point: 20,15
Specify next point: 45,10
Specify next point: 70,25
Specify next point: Enter (to finish)

16. POINT & DONUT

POINT places a single reference marker at an exact coordinate, often used for surveying/reference marks. DONUT draws a filled ring (or solid filled circle if the inside diameter is set to 0), often used to mark rebar cross-sections in civil drawings or as a filled indicator dot.

  • Type POINT or PO, then click or type the coordinate. Use DDPTYPE to change the point's display style/size.
  • Type DONUT, enter the inside diameter, then the outside diameter, then pick the centre point(s).
Command: DONUT
Specify inside diameter of donut <0.5000>: 0
Specify outside diameter of donut <1.0000>: 10
Specify center of donut or <exit>: 30,30   (draws a solid filled dot)

17. HATCH (Shortcut: H)

Fills a bounded, enclosed area with a repeating pattern – used to show sectioned material in mechanical drawings and materials like brickwork, earth, or concrete in civil drawings.

  • Type HATCH or H; the Hatch Creation ribbon tab opens.
  • Choose a Pattern (e.g. ANSI31 diagonal lines for metal sections, AR-BRSTD for brick, EARTH for soil).
  • Set the Scale of the pattern to suit the drawing size.
  • Click inside the closed boundary you want filled (Pick Points), or select the bounding objects directly (Select Objects).
  • Press Enter to apply.
Command: HATCH
Pick internal point or [Select objects]: (click inside the closed boundary)
Pattern: ANSI31   Scale: 1   Angle: 0
Press Enter to accept

18. REGION & BOUNDARY

REGION converts a closed 2D shape (made of lines/arcs/polylines) into a single 2D solid area object, which can then have its area/centroid properties queried, and can be combined with other regions using Union, Subtract, or Intersect. BOUNDARY automatically traces a closed polyline or region from overlapping/enclosing objects by clicking a point inside them.

  • Type REGION, select the closed set of objects, press Enter.
  • Type BOUNDARY, click inside an enclosed area to auto-generate its outline as a new object.
Command: REGION
Select objects: (select the 4 lines forming a closed rectangle)
Select objects: Enter
1 loop extracted. 1 Region created.

Part C — Modify Commands

19. MOVE (Shortcut: M)

Relocates one or more selected objects from one place to another without changing their size, shape, or rotation.

  • Type MOVE or M, select the object(s), press Enter.
  • Specify a base point (a point on the object to move from).
  • Specify the destination point, or type a relative displacement.
Command: MOVE
Select objects: (select the object)
Select objects: Enter
Specify base point: (click a corner of the object)
Specify second point: @50,0    (moves the object 50 units to the right)

20. COPY (Shortcut: CO or CP)

Creates one or more duplicate copies of selected objects, leaving the originals in place. Works identically to MOVE but keeps the source object.

  • Type COPY or CO, select object(s), press Enter.
  • Specify a base point, then the destination point(s) – multiple copies can be placed one after another until Enter/Esc is pressed.
Command: COPY
Select objects: (select the object)
Select objects: Enter
Specify base point: 0,0
Specify second point: @0,40
Specify second point: @0,80    (a second copy placed further along)
Specify second point: Enter

21. ROTATE (Shortcut: RO)

Turns selected objects around a fixed base point by a specified angle.

  • Type ROTATE or RO, select object(s), press Enter.
  • Specify the base point (the pivot point).
  • Enter the rotation angle (positive = counter-clockwise), or type C to copy while rotating (Copy option), or R to reference an existing angle and rotate to a new one.
Command: ROTATE
Select objects: (select the object)
Select objects: Enter
Specify base point: (click the pivot point)
Specify rotation angle or [Copy/Reference]: 45

22. SCALE (Shortcut: SC)

Enlarges or reduces selected objects uniformly (equally in X and Y) about a chosen base point.

  • Type SCALE or SC, select object(s), press Enter.
  • Specify the base point.
  • Enter a scale factor (e.g. 2 = double size, 0.5 = half size), or type R to scale by reference length.
Command: SCALE
Select objects: (select the object)
Select objects: Enter
Specify base point: (click reference point)
Specify scale factor or [Copy/Reference]: 0.5

23. MIRROR (Shortcut: MI)

Creates a mirrored (flipped) copy of selected objects across a mirror line, ideal for symmetrical parts and layouts (e.g. mirroring half a bracket to complete it, or mirroring a room layout).

  • Type MIRROR or MI, select object(s), press Enter.
  • Specify the first point of the mirror line, then the second point (use Ortho for a perfectly vertical/horizontal mirror line).
  • Choose whether to erase the original object (type Y) or keep it (type N, the default).
Command: MIRROR
Select objects: (select the half-shape)

Specify second point of mirror line: 60,100

24. OFFSET (Shortcut: O)

Creates a new parallel copy of a line, polyline, circle, or arc at a specified distance – extremely useful for creating wall thicknesses in civil plans or parallel outlines in mechanical parts.

  • Type OFFSET or O.
  • Enter the offset distance.
  • Select the object to offset, then click on the side where the copy should appear.
  • Repeat for other objects, or press Enter/Esc to finish.
Command: OFFSET
Specify offset distance or [Through/Erase/Layer] <1.0000>: 230   (e.g. 230mm wall thickness)
Select object to offset or <exit>: (click the wall line)
Specify point on side to offset: (click outside the wall to offset outward)

25. TRIM (Shortcut: TR)

Cuts and removes the portion of an object that extends past a chosen cutting-edge boundary, keeping only the required part.

  • Type TRIM or TR, select the cutting-edge object(s), press Enter (or just press Enter to select all as possible edges).
  • Click on the part of the object(s) you want removed – repeat for multiple trims.
  • Hold Shift while clicking to instead extend an object (switches to Extend behaviour temporarily).
Command: TRIM
Select cutting edges ...
Select objects or <select all>: (select the boundary line)
Select objects: Enter
Select object to trim or shift-select to extend: (click the overhanging part to delete)

26. EXTEND (Shortcut: EX)

Lengthens a selected object until it meets a chosen boundary edge – the exact opposite operation to TRIM.

  • Type EXTEND or EX, select the boundary edge object(s), press Enter.
  • Click on the object that needs to be stretched out to meet that boundary.
  • Hold Shift while clicking to instead trim (switches to Trim behaviour temporarily).
Command: EXTEND
Select boundary edges ...
Select objects or <select all>: (select the boundary line)
Select objects: Enter
Select object to extend or shift-select to trim: (click the short line to stretch it to the boundary)

27. FILLET (Shortcut: F)

Joins two lines (or other objects) with a smooth rounded arc of a specified radius at their corner – used for rounded corners on mechanical parts (avoiding stress concentration) and rounded plan corners in civil work.

  • Type FILLET or F.
  • Type R to set the fillet radius, enter the value.
  • Click the first object, then click the second object – AutoCAD automatically trims/extends and adds the rounded corner.
  • Setting radius to 0 creates a sharp square corner instead (useful for squaring off a corner).
Command: FILLET
Select first object or [Undo/Polyline/Radius/Trim/Multiple]: R
Specify fillet radius <0.0000>: 10
Select first object: (click line 1)
Select second object: (click line 2)

28. CHAMFER (Shortcut: CHA)

Joins two lines with a flat angled bevel edge instead of a curve – standard on mechanical parts to remove sharp edges and ease assembly.

  • Type CHAMFER or CHA.
  • Type D to set two chamfer distances (or A for a distance + angle method), enter the values.
  • Click the first line, then click the second line.
Command: CHAMFER
Select first line or [Undo/Polyline/Distance/Angle/Trim/Method/Multiple]: D
Specify first chamfer distance <0.0000>: 5
Specify second chamfer distance <5.0000>: 5
Select first line: (click line 1)
Select second line: (click line 2)

29. ARRAY – Rectangular, Polar, Path (Shortcut: AR)

Creates multiple evenly-spaced copies of an object in one operation. Three types are available depending on the pattern needed.

  • Rectangular Array (ARRAYRECT) – copies arranged in rows and columns (e.g. a grid of columns in a civil plan, or a grid of holes).
  • Polar Array (ARRAYPOLAR) – copies arranged evenly around a centre point (e.g. bolt holes around a circular flange).
  • Path Array (ARRAYPATH) – copies distributed evenly along a curve or path (e.g. railing balusters along a staircase edge).

Command: ARRAYPOLAR

30. STRETCH (Shortcut: S)

Moves the vertices/endpoints of objects caught inside a crossing selection window, while leaving fully-enclosed objects untouched – used to resize part of a shape without redrawing it, e.g. lengthening one wall of a room.

  • Type STRETCH or S.
  • Select objects using a crossing window (drag right-to-left) that only partially encloses the geometry to be stretched.
  • Specify a base point, then the displacement point.
Command: STRETCH
Select objects to stretch by crossing-window or crossing-polygon...

Select objects: Enter
Specify base point: (click a reference point)

31. BREAK (Shortcut: BR)

Splits an object into two, or removes a section between two picked points – used to insert a gap in a line for a wall opening, or to separate an object for editing.

  • Type BREAK or BR, select the object at the first break point.
  • Specify the second break point (or type F to redefine the first point precisely).
  • "Break at Point" (a separate tool) splits an object into two with no gap at all.
Command: BREAK
Select object: (click the line at the first break point)
Specify second break point [First point]: (click the second break point)

32. JOIN (Shortcut: J)

Combines two or more separate but aligned/collinear objects (lines, arcs, polylines) into a single continuous object – the reverse operation of BREAK or EXPLODE.

  • Type JOIN or J.
  • Select the objects to be joined (they must be collinear for lines, or share endpoints).
  • Press Enter to merge them into one object.
Command: JOIN
Select source object or multiple objects to join at once: (select all line segments)
Select objects to join: Enter

33. EXPLODE (Shortcut: X)

Breaks a compound object (polyline, rectangle, block, hatch, dimension) down into its individual, separate basic components (lines/arcs). Used when a single part of a combined object needs to be edited independently.

  • Type EXPLODE or X, select the object(s), press Enter.
  • Note: exploding removes special properties like polyline width or block attribute values.
Command: EXPLODE
Select objects: (select the rectangle)
Select objects: Enter    (the rectangle becomes 4 separate lines)

34. MATCH PROPERTIES (Shortcut: MA)

Copies the properties (layer, colour, linetype, lineweight, and for text/dimensions, style) from one "source" object onto other "destination" objects – a fast way to make objects consistent without manually changing each property.

  • Type MATCHPROP or MA.
  • Click the source object (the one with the correct properties).
  • Click each destination object that should take on those same properties.
Command: MATCHPROP
Select source object: (click the correctly-formatted line)
Select destination object(s): (click the objects to update)
Select destination object(s): Enter

Part D — Annotation: Text & Dimensioning

35. Single Line Text (DTEXT / TEXT)

Places one or more independent lines of text, where each line is a separate text object – suited for short labels such as room names or part numbers.

  • Type DTEXT (or TEXT), specify the start point.
  • Enter the text height, then the rotation angle.
  • Type the text; press Enter to move to a new line, press Enter twice (or Esc) to finish.
Command: DTEXT
Specify start point of text: 10,10
Specify height <2.5000>: 5
Specify rotation angle of text <0>: 0
Enter text: BEDROOM 1
Enter text: Enter (twice to finish)

36. Multiline Text & Text Styles (MTEXT, STYLE)

MTEXT creates a single paragraph-style text object that can wrap across multiple lines within a defined width – suited for notes, specifications, and title block text. STYLE lets you define the font, width factor, and obliquing angle used by text and dimensions.

  • Type MTEXT or T, drag out a text boundary box, then type the paragraph in the in-place editor.
  • Type STYLE to open the Text Style manager; set Font (e.g. Arial, Romans.shx for drafting), Height, and Width Factor.
Command: MTEXT
Specify first corner: 0,0
Specify opposite corner: 100,20
(Type paragraph text in the editor, e.g.:)
NOTE: ALL DIMENSIONS ARE IN MILLIMETRES UNLESS OTHERWISE STATED.

37. Dimension Basics & Dimension Style (DIMSTYLE)

A dimension object records and displays a measured distance or angle automatically, made up of extension lines, dimension lines, arrowheads, and the dimension text. A Dimension Style controls how all of these look (arrow size, text height, units, precision) consistently across the whole drawing.

  • Type DIMSTYLE or D to open the Dimension Style Manager.
  • Click "New" to create a style, then configure: Lines (extension line offset), Symbols and Arrows (arrow size), Text (height, position), Primary Units (precision, e.g. 0.0).
  • Set this style "Current" before placing dimensions.
  • Mechanical drawings usually use 2 decimal precision in mm; civil drawings often use whole numbers in mm or metres to 2 decimals.

38. Linear, Aligned & Angular Dimensions

These are the three most common dimension types for measuring straight distances and angles.

  • DIMLINEAR – measures a purely horizontal or vertical distance between two points.
  • DIMALIGNED – measures the true distance between two points along their own slanted direction (not forced horizontal/vertical).
  • DIMANGULAR – measures the angle between two lines, or three points.
Command: DIMLINEAR
Specify first extension line origin: (click one endpoint)

Specify dimension line location: (click to place the dimension line/text)

Command: DIMANGULAR

Specify dimension arc line location: (click to place)

39. Radius, Diameter & Leader Dimensions

Used specifically for circular features (holes, fillets, shafts) and for pointing out notes on a specific feature.

  • DIMRADIUS – labels the radius of a selected circle or arc, prefixed with "R".

  • LEADER / QLEADER / MLEADER – draws an arrow line from a feature to a text note placed alongside it, e.g. "4 HOLES, Ø10" pointing at a bolt-hole pattern.

Part E — Organization & Output Tools

41. BLOCK & INSERT

A block is a group of objects combined and saved as a single reusable symbol within a drawing – for example a door symbol, a bolt symbol, or a north-arrow. Once defined, it can be inserted repeatedly at different locations, scales, and rotations, and if the block definition is edited, every inserted copy updates automatically.

  • Draw the symbol once, then type BLOCK (or B).
  • Give it a name, specify a base (insertion) point, then select the objects to include.
  • To place it elsewhere, type INSERT, choose the block name, set scale/rotation, and click to place.
Command: BLOCK
Name: DOOR-900
Base point: (click the hinge point of the door)
Select objects: (select the drawn door symbol)

Command: INSERT
Name: DOOR-900
Specify insertion point: (click on the wall opening)
Specify scale factor <1>: 1
Specify rotation angle <0>: 90

42. WBLOCK & Attributes (ATTDEF)

WBLOCK ("Write Block") saves a block (or selected objects) out as its own separate DWG file on disk, so it can be reused across different drawings/projects, not just within the current file. ATTDEF (Attribute Definition) adds an editable text field to a block, such as a part number or room name, so every inserted copy can show different information while keeping the same graphic symbol.

  • Type WBLOCK, select the block/objects, choose a file location and name, click OK.
  • Type ATTDEF before creating the block: set a Tag (e.g. PARTNO), a Prompt (e.g. "Enter part number"), and a Default value.
  • Include the attribute text along with the graphics when running BLOCK, so it becomes part of the block definition.
Command: ATTDEF
Tag: PARTNO
Prompt: Enter part number
Default: PN-001
(place the attribute text, then run BLOCK including this text + the symbol)

43. Layouts – Model Space vs Paper Space

Model Space is where the actual drawing is created at true, real-world 1:1 scale. Paper Space (Layout) is a separate sheet representing the actual printed page (e.g. A3), onto which one or more scaled "windows" (viewports) into Model Space are placed, along with the title block, border, and drawing notes.

  • Click the "Layout1" tab at the bottom of the screen to switch to paper space.
  • Insert or draw a title block and border directly in the layout (it represents the physical sheet).
  • Use MVIEW (see next topic) to open a window showing the model space drawing at a controlled scale.

44. Viewports (MVIEW)

A viewport is a "window" placed inside a Layout that displays the Model Space drawing at a specific, locked scale – this is how a full-size drawing is correctly scaled down to fit on a printed sheet.

  • On a Layout tab, type MVIEW, then drag a rectangle to create the viewport window.
  • Double-click inside the viewport to enter it (border turns bold), then set the display scale from the Viewport Scale flyout in the status bar (e.g. 1:100 for a civil floor plan, 1:1 or 1:2 for a mechanical part).
  • Double-click outside the viewport to lock back into Paper Space.
  • Lock the viewport scale afterward to prevent accidental zooming from changing it.
Command: MVIEW
Specify corner of viewport: (click first corner)
Specify opposite corner: (click opposite corner)
(double-click inside -> set scale to 1:50 from the status bar scale list)

45. PLOT / Printing a Drawing

PLOT sends the finished drawing (usually from a Layout) to a printer/plotter or exports it as a PDF, at the correct paper size and scale.

  • Type PLOT (Ctrl+P), or click the Plot icon while on the Layout tab.
  • Choose the Printer/Plotter (or "DWG to PDF" for a digital file).
  • Set Paper Size (e.g. A3, A4) and Plot Area to "Layout".
  • Set Plot Scale to 1:1 when plotting a Layout (since the viewport already controls the model scale).
  • Click Preview to check, then click OK to plot.

Part F — Mechanical Drawing Applications

46. Orthographic Projection Basics

Orthographic projection represents a 3D object using multiple flat 2D views (Front View, Top View, Side View), each showing the object as seen from a different direction, aligned with each other. This is the core method for producing manufacturable mechanical drawings.

  • First Angle Projection – the object is imagined between the observer and the plane. The Top View is placed below the Front View, and the Side View is placed to the right, viewed from the left. Standard in India, Europe, and most of Asia (symbol: truncated cone with wide end).
  • Third Angle Projection – the plane is imagined between the observer and the object. The Top View is placed above the Front View. Standard in the USA and Canada (symbol: truncated cone with narrow end).
  • Views must always be drawn in alignment using vertical/horizontal construction (XLINE) so features line up correctly between views.

47. Sectional Views

A sectional view shows the object as if cut through by an imaginary cutting plane, revealing internal features (holes, ribs, wall thickness) that would otherwise be hidden. The cut surface is shown with hatching.

  • Decide the cutting plane location and draw a Cutting Plane Line (thick dashed/dash-dot line with arrows showing viewing direction), labelled e.g. A-A.
  • Draw the sectional view as a separate view showing what is revealed by that cut.
  • Apply HATCH (typically ANSI31 pattern for metal) to all solid material surfaces that the cutting plane passes through.
  • Ribs, webs, and shafts are conventionally NOT hatched even if the cutting plane passes along their length.

48. Dimensioning Standards for Mechanical Drawings

Mechanical dimensioning must clearly and unambiguously define every size needed to manufacture the part, following standard conventions.

  • Dimension lines should not cross each other; place smaller dimensions closer to the object, larger overall dimensions further out.
  • Diameters are marked with the Ø symbol (DIMDIAMETER); radii with "R" (DIMRADIUS).
  • Tolerances specify the permitted variation in a dimension, e.g. 50 ±0.05, entered in the Dimension Style's Tolerance tab or typed directly into the dimension text.
  • Surface finish, material, and general tolerance notes are added as MTEXT notes near the title block.
  • A standard title block (drawn once, saved as a block) should include: Part Name, Material, Scale, Drawn By, Date, and Drawing Number.

49. Standard Mechanical Symbols & Line Types

  • Continuous thick line – visible outlines and edges.
  • Continuous thin line – dimension lines, extension lines, leader lines, hatching.
  • Dashed line (HIDDEN linetype) – edges/features hidden behind the visible surface.
  • Centre line (CENTER linetype, thin) – axes of symmetry, hole centres, shaft centrelines – alternating long-short dashes.
  • Ø before a value = diameter; R before a value = radius; ± = tolerance; ° = degrees.

Part G — Civil Drawing Applications

50. Civil Drawing Types: Plan, Elevation, Section

  • Plan – a top-down (bird's eye) view of a building floor, showing walls, doors, windows, and room layout, as if a horizontal cut was taken about 1m above floor level.
  • Elevation – a straight-on view of one exterior face (front/side/rear) of a building, showing height, window/door positions, and roof outline.
  • Section – a vertical cut through the building showing floor-to-floor heights, foundation depth, and internal construction details.

51. Scale in Civil Drawings

Because buildings are far too large to draw at real size on paper, civil drawings are always drawn full-size (1:1) in Model Space, then plotted at a reduced scale through the Layout viewport.

  • Site/Layout plans: commonly 1:200 or 1:500.
  • Floor plans, elevations, sections: commonly 1:50 or 1:100.
  • Detail drawings (door/window/foundation details): commonly 1:10 or 1:20.
  • Always draw at true size (1:1) in Model Space – scale is only applied when setting up the viewport in the Layout (see Section 44).

52. Civil Drafting Symbols & Conventions

  • Walls – drawn as two parallel lines (OFFSET) at true wall thickness (e.g. 230mm brick wall), often filled with a hatch pattern in section.
  • Doors – shown as a break in the wall with a line (the door leaf) and a quarter-circle arc (ARC) showing the swing path.
  • Windows – shown as a break in the wall with two/three parallel lines across the opening.
  • North Arrow – a symbol block placed on site/floor plans indicating true north orientation.
  • Grid/Axis lines – centre lines (labelled 1,2,3... and A,B,C...) used to locate columns and structural elements consistently across all drawings.

53. Wall, Door & Window Representation – Method

The standard method for drawing walls with door and window openings combines OFFSET, TRIM/BREAK, and ARC.

  • Draw the wall centre line first (single LINE, on a Grid/Axis layer).
  • OFFSET it by half the wall thickness on each side to get the two wall faces.
  • At each opening location, use BREAK (or TRIM with construction lines) to remove the wall lines across the opening width.
  • For a door: draw the door leaf as a short LINE at the opening edge, then draw its swing arc with ARC (centre at the hinge point, radius = door width).
  • For a window: draw two/three short parallel LINEs across the opening gap.

Assignment C1 — Draw a Simple Room Floor Plan

Task: Draw the plan of a single room, 4m x 3.5m internal size, 230mm thick walls, with one 900mm door and one 1200mm window, fully dimensioned. (Draw at 1:1 in mm: 4000 x 3500.)

Solution

   Command: RECTANG
   Specify first corner point: 0,0
   Specify other corner point: @4230,3730     (internal size + wall thickness)

2. Offset the outline to create wall thickness (230mm wall = 115mm each side):
   Command: OFFSET -> distance 115 -> select each edge -> offset outward
   Command: OFFSET -> distance 115 -> select each edge -> offset inward
   (Result: two parallel rectangles representing the inner and outer wall faces)

3. Create the door opening on the bottom wall:
   Command: BREAK
   Select object: (click the bottom wall line)
   Specify second break point: (click 900mm along, using OSNAP + typed distance)
   (repeat BREAK on both the inner and outer wall lines at the same location)

   Command: LINE -> from the opening edge, length 900mm, perpendicular to wall
   Command: ARC -> Center: hinge point -> Start: door leaf end -> Included angle: 90

5. Create the window opening on the side wall using BREAK the same way (1200mm wide),
   then draw 2 short parallel LINEs across the gap to represent the window.

6. Switch to DIMENSION layer:
   DIMLINEAR along each internal wall face -> 4000 and 3500
   DIMLINEAR across the door opening -> 900
   DIMLINEAR across the window opening -> 1200

Assignment C3 — Draw a Site / Layout Plan with Setbacks

Task: A rectangular plot is 15m x 20m. Draw the plot boundary and the building footprint (10m x 12m) respecting a 3m front setback, 2m rear setback, and 1.5m side setbacks on both sides.

Solution

   the 10m x 12m building footprint rectangle using OSNAP Intersection to

                    -> Other corner: @10000,12000

4. Delete or freeze the construction/setback guide lines once the building
   rectangle is confirmed correctly placed (or keep them on a non-plotting layer).

5. Dimension: plot boundary (15000 x 20000), building footprint (10000 x 12000),
   and each setback distance (1500, 1500, 3000, 2000) using DIMLINEAR.

6. Insert a North Arrow block at the top corner of the plot, and label the
