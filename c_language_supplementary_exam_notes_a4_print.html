Past Paper Questions and Proper Answers

1(a). Differentiate between RAM and ROM.
Answer: RAM is volatile memory used for temporary data storage while a program is running. It allows both read and write access. ROM is non-volatile memory used to store permanent instructions like firmware or boot code. It is mainly read-only and retains data even when power is off.
1(b). Write in detail about algorithms.
Answer: An algorithm is a finite sequence of well-defined steps for solving a problem. It must have input, output, clear steps, and terminate after a finite number of operations. Common properties are definiteness, finiteness, effectiveness, input, and output. Example: algorithm to find the largest number from n inputs.
Algorithm Example:
Algorithm MaxNumber Input: n numbers Output: largest number 1. Read n 2. Read first number and store in max 3. For i = 2 to n a. Read next number b. If number > max, assign it to max 4. Print max End
2(a). Define a data type. Mention the different data types supported by C language, giving one example each.
Answer: A data type defines the kind of data a variable can store and the operations allowed on it. In C, basic data types include char, int, float, double, and void. Derived types include arrays, pointers, structures, and unions. Examples: char ch = 'A';, int x = 25;, float pi = 3.14f;, double d = 8.12345;.
2(b). What are control flow statements? Write a C program to find factorial of a given number using loops.
Answer: Control flow statements control the order in which instructions are executed. They include if, if-else, switch, for, while, do-while, break, and continue. A factorial number is the product of all positive integers up to n.
Code Example:
#include <stdio.h> int main() { int n, i, fact = 1; printf("Enter a number: "); scanf("%d", &n); for (i = 1; i <= n; i++) fact *= i; printf("Factorial of %d = %d\n", n, fact); return 0; }
3(a). Discuss about function definition and function call in C. Write a C program using function to print Fibonacci series of a given number.
Answer: A function is a block of code that performs a specific task. A function is defined once and can be called many times. The function definition includes the return type, name, and parameters. Calling a function means executing that function. Example below prints Fibonacci series using a function.
Code Example:
#include <stdio.h> void fibonacci(int n) { int a = 0, b = 1, c; printf("Fibonacci Series: "); for (int i = 0; i < n; i++) { printf("%d ", a); c = a + b; a = b; b = c; } printf("\n"); } int main() { int n = 8; fibonacci(n); return 0; }

4(b). Give the syntax and importance of void pointer with an example.

5(a). How is structure different from an array? Write a C program to create an array of 100 textbooks with title, price, and number of pages using structures and print them.
Answer: An array stores only values of the same type, while a structure can store different types in one record. A structure is useful to store a book record containing title, price, and pages.
Code Example:
#include <stdio.h> struct Book { char title[30]; int price; int pages; }; int main() { struct Book books[2] = { {"C Programming", 250, 400}, {"Data Structures", 300, 500} }; for (int i = 0; i < 2; i++) { printf("Title: %s Price: %d Pages: %d\n", books[i].title, books[i].price, books[i].pages); } return 0; }
5(b). Elaborate self-referential structure with an example.
Answer: A self-referential structure contains a pointer member that points to a variable of the same type. It is used for linked lists, trees, and graphs. The pointer is used to connect nodes.
Code Example:

7(a). Write an algorithm for implementation of quick sort with an example.
Answer: Quick sort partitions the array around a pivot, placing smaller elements to the left and larger elements to the right. Then it recursively sorts the subarrays. Complexity is $O(n \log n)$ on average and $O(n^2)$ in the worst case.
Algorithm Sketch:
QuickSort(arr, low, high) 1. If low < high: a. pivot = partition(arr, low, high) b. QuickSort(arr, low, pivot-1) c. QuickSort(arr, pivot+1, high) 2. End
7(b). Define time complexity. Compare and construct time complexity for linear search and binary search with an example.
Answer: Time complexity measures how the running time of an algorithm grows with input size. Linear search checks each element one by one and takes $O(n)$ time. Binary search works on sorted arrays and reduces the search interval by half each time, giving $O(log n)$ time.
8(a). Write an algorithm to convert infix expression to postfix expression.
Answer: In postfix notation, operators appear after operands. Use a stack. When an operand is read, output it. When an operator is read, pop higher-precedence operators, then push the current operator. When a closing parenthesis is seen, pop until the opening parenthesis is found.
Example:
Infix: A + B * C Postfix: A B C * +
8(b). Write an algorithm for implementation of Stack using linked list.
Answer: A stack using a linked list stores each element as a node. Push inserts a new node at the front. Pop removes the front node. This method uses dynamic memory and does not suffer from fixed-size limitations.
Stack Push/Pop Idea:
Push(value): 1. create new node 2. set new node data = value 3. new node next = top 4. top = new node Pop(): 1. if top == NULL, stack underflow 2. else delete top node and move top to next
Extra Important Question 1. Explain storage classes in C.
Answer: Storage classes determine the lifetime, scope, and default value of variables. The four main storage classes are auto, register, static, and extern. auto is local and default, register stores in CPU register when possible, static retains value between function calls, and extern refers to a global variable defined elsewhere.
Extra Important Question 2. What is structure? How is it different from union?
Answer: A structure stores different data types in a single record and allocates separate memory for each member. A union shares the same memory space for all members. Structure is used when all members are needed together; union is used when one member is active at a time.
Extra Important Question 3. Explain merge sort with an example.
Answer: Merge sort divides the list into two halves, sorts each half recursively, and then merges the sorted halves. It has a time complexity of $O(n \log n)$ in all cases.

Paper Q2. Draw a flow chart to check whether the given number is perfect number or not.
Answer: A perfect number is a number whose sum of proper divisors equals the number itself. For example, 6 is perfect because $1 + 2 + 3 = 6$. The flowchart reads the input number, initializes a sum to 0, checks every divisor from 1 to half the number, adds each divisor to the sum, and then compares the sum with the original number. If they are equal, print "Perfect Number"; otherwise print "Not Perfect".
Flowchart Logic:
Start Read n sum = 0 for i = 1 to n/2 if n % i == 0 sum = sum + i if sum == n print "Perfect" else print "Not Perfect" End

Paper Q8. Explain the merge sort algorithm with an example.
Answer: Merge sort is a divide-and-conquer sorting algorithm. It splits the array into two halves, sorts each half recursively, and then merges the two sorted halves to produce a completely sorted array. It is efficient and stable and has a time complexity of $O(n \log n)$ in the best, average, and worst cases.
Merge Sort Idea:
MergeSort(A, low, high) 1. If low < high a. mid = (low + high) / 2 b. MergeSort(A, low, mid) c. MergeSort(A, mid + 1, high) d. Merge(A, low, mid, high) 2. End
Paper Q9. What is stack? Explain in brief stack operations and applications. Explain how a queue can be implemented using arrays.
Answer: A stack is a linear data structure that follows the Last In First Out (LIFO) principle. Its main operations are push (insert on top), pop (remove from top), and peek (view top element). Stacks are used in expression evaluation, recursion, backtracking, and function call management. A queue is a linear data structure that follows the First In First Out (FIFO) principle. It can be implemented using arrays by maintaining front and rear indices, where insertion is done at the rear and deletion is done from the front.
Array Queue Idea:
Queue operations using array: - Enqueue: insert at rear - Dequeue: remove from front - Front: first element - Rear: last element - Overflow: when rear == size - 1 - Underflow: when front == rear and queue is empty
Extra Important Question 4. Write an algorithm for bubble sort and explain its working with an example.
Answer: Bubble sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. In every pass, the largest unsorted element moves to the end. It is simple to understand but inefficient for large data because its time complexity is $O(n^2)$ in the worst case.
Bubble Sort Idea:
BubbleSort(arr, n) 1. Repeat for i = 0 to n-1 2. Repeat for j = 0 to n-i-2 if arr[j] > arr[j+1] swap(arr[j], arr[j+1]) 3. End
Extra Important Question 5. Explain selection sort with an example. State its time complexity.
Answer: Selection sort finds the smallest element in the remaining unsorted list and places it at the beginning of the unsorted section. It repeats this process until the whole array is sorted. It has a time complexity of $O(n^2)$ because it scans the array repeatedly.
Selection Sort Idea:
SelectionSort(arr, n) 1. for i = 0 to n-1 a. find smallest element in arr[i..n-1] b. swap it with arr[i] 2. End
Extra Important Question 6. Write an algorithm and example for insertion sort.
Answer: Insertion sort builds the final sorted array one element at a time. Each new element is inserted into its correct position among the already sorted elements. It is efficient for small arrays and has time complexity of $O(n^2)$ in the worst case.
Insertion Sort Idea:
InsertionSort(arr, n) 1. for i = 1 to n-1 a. key = arr[i] b. j = i - 1 c. while j >= 0 and arr[j] > key arr[j+1] = arr[j] j = j - 1 d. arr[j+1] = key 2. End
Extra Important Question 7. Explain quick sort algorithm with an example and compare with merge sort.
Answer: Quick sort is a divide-and-conquer sorting algorithm that uses a pivot element to partition the array into smaller and larger parts. It then recursively sorts the two partitions. Its average time complexity is $O(n \log n)$, but worst case can be $O(n^2)$. Merge sort is stable and has consistent $O(n \log n)$ time in all cases; quick sort is usually faster in practice but less stable.
Quick Sort Idea:
QuickSort(arr, low, high) 1. if low < high a. pivot = partition(arr, low, high) b. QuickSort(arr, low, pivot-1) c. QuickSort(arr, pivot+1, high) 2. End
Extra Important Question 8. Define binary search and compare it with linear search.
Answer: Linear search checks elements one by one from the start until it finds the target, so its time complexity is $O(n)$. Binary search works only on sorted arrays and repeatedly halves the search space, giving time complexity $O(\log n)$. Binary search is faster for large sorted arrays, whereas linear search is simpler and works on unsorted arrays.
Extra Important Question 9. What is recursion? Write a C program to find factorial using recursion.
Answer: Recursion is a technique in which a function calls itself to solve a smaller version of the same problem. It must have a base condition to stop infinite recursion. A recursive factorial program uses a base case when the input number becomes 0 or 1.
Recursive Factorial Example:
#include <stdio.h> int fact(int n) { if (n == 0 || n == 1) return 1; return n * fact(n - 1); } int main() { int n = 5; printf("Factorial = %d\n", fact(n)); return 0; }

Extra Important Question 11. Explain operator precedence and associativity in C with an example.
Answer: Operator precedence defines the order in which operators are evaluated in an expression. Associativity decides the order when operators have the same precedence. For example, in the expression a + b * c, multiplication is evaluated before addition because * has higher precedence than +. In expressions like a - b - c, left associativity is applied.
Extra Important Question 12. Differentiate between call by value and call by reference with examples.
Answer: In call by value, a copy of the actual argument is passed to the function, so changes inside the function do not affect the caller. In call by reference, the memory address of the variable is passed, so changes inside the function affect the original value. Call by reference is usually implemented using pointers.
Example:
#include <stdio.h> void swapByValue(int a, int b) { int t = a; a = b; b = t; } void swapByReference(int *a, int *b) { int t = *a; *a = *b; *b = t; } int main() { int x = 5, y = 10; swapByValue(x, y); printf("After value call: %d %d\n", x, y); swapByReference(&x, &y); printf("After reference call: %d %d\n", x, y); return 0; }

Extra Important Question 15. Explain linked list. Write the algorithm for insertion and deletion in a singly linked list.

Linked List Idea:

Extra Important Question 18. Explain infix to postfix conversion using a stack. Convert A + B * C into postfix form.
Answer: Infix notation places the operator between operands, whereas postfix puts the operator after the operands. To convert, scan the expression left to right. If an operand is read, append it to the output. If an operator is read, pop operators of higher or equal precedence from the stack and then push the current operator. Parentheses are handled by popping until the opening parenthesis is found. For A + B * C, the postfix expression is A B C * +.
Extra Important Question 19. Differentiate between queue and stack. Write a short note on queue operations using linked list.
Answer: A stack follows LIFO and a queue follows FIFO. In a queue, insertion occurs at the rear and deletion occurs at the front. A linked-list implementation uses two pointers: front and rear. New nodes are added at the rear and removed from the front, making it dynamic and flexible when the size is not known in advance.
Extra Important Question 20. Write a note on searching methods in C. Compare linear search and binary search with examples.
Answer: Searching is the process of finding a required item in a given set of data. Linear search checks each element one by one and is suitable for unsorted arrays. Binary search works only on sorted arrays by repeatedly dividing the search interval. The time complexity of linear search is $O(n)$ and that of binary search is $O(\log n)$.
