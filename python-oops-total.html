Section B: Theory & Programming Questions (10 x 9 = 90 Marks)

  1. Classes, Objects, Constructors and Methods: Explain the difference between a class and an object. Write a Python program to create a class Student with instance variables name, roll_no, and marks. Use a constructor to initialize the values and create a method to display the student details.
  2. Instance and Static/Class Variables: Explain the difference between an instance variable and a static/class variable. Write a Python program to create an Employee class having instance variables name and salary, and a class variable company. Create multiple objects and display their details.
  3. Encapsulation: What is encapsulation? Explain public and private data members in Python. Write a program to create a class BankAccount with a private variable __balance and methods deposit(), withdraw(), and display_balance().
  4. Inheritance, Method Overriding and super(): Explain inheritance and method overriding. Write a Python program with a parent class Vehicle containing a constructor and method display(). Create a child class Car that overrides the method and uses super() to call the parent constructor.
  5. Multiple Inheritance and Polymorphism: Explain multiple inheritance and polymorphism. Write a Python program with two parent classes Father and Mother and a child class Child inheriting from both. Also demonstrate polymorphism using a common method named display().
  6. Magic Methods: What are magic methods in Python? Explain the use of __init__() and __str__(). Write a Python program to create a class Book with title and price and use __str__() to display the object details using print().
  7. Operator Overloading: What is operator overloading? Explain with an example. Write a Python program to create a class Distance containing feet and inches. Overload the + operator using __add__() to add two Distance objects.
  8. Composition and Aggregation: Explain the difference between composition and aggregation. Write a Python program to demonstrate a Car containing an Engine object using composition. Also explain how a Department and Teacher relationship can represent aggregation.
  9. Exception Handling: Explain try, except, else, and finally blocks. Write a Python program that accepts two numbers and performs division. Handle ZeroDivisionError and ValueError using appropriate exception handling.
  10. File Handling with OOP: Create a Python class StudentFile with methods write_data(), read_data(), and append_data(). Write student information to a text file, read the contents, and append new student information. Use appropriate exception handling to handle file-related errors.
