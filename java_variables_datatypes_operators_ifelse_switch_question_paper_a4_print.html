Section A: Multiple Choice Questions (10 x 1 = 10 Marks)

  1. Which is a valid declaration in Java? A) int a = 10; B) integer a = 10; C) num a = 10; D) var int a = 10;
  2. What is the output of System.out.print(15 / 4); ? A) 3.75 B) 3 C) 4 D) 3.0
  3. Which operator is used for logical AND? A) & B) || C) && D) !
  4. What is the value of 7 % 3? A) 1 B) 2 C) 3 D) 0
  5. What will this print? int x = 10; if (x > 5) System.out.print("Yes"); else System.out.print("No"); A) Yes B) No C) 10 D) Compile-time error
  6. Which data type stores decimal values in Java? A) int B) boolean C) double D) char
  7. What is the output? int d = 2; switch (d) { case 1: System.out.print("Mon"); break; case 2: System.out.print("Tue"); break; default: System.out.print("Invalid"); } A) Mon B) Tue C) Invalid D) No output
  8. Which keyword is used with if to check another condition when first condition is false? A) then B) else C) case D) default
  9. What is the output? int a = 5; int b = 3; System.out.print(a > b && b > 0); A) true B) false C) 1 D) Error
  10. Which is the correct relational operator to test "not equal"? A) <> B) ~= C) != D) =!

Section B: Fill In The Blanks (10 x 1 = 10 Marks)

  1. In Java, comparing two primitive numeric values for equality uses __________.
  2. The smallest integral data type in Java is __________.
  3. The expression 5 / 2 (both int) evaluates to __________.
  4. In switch, if break is omitted, control __________ to the next case.
  5. The operator with higher precedence between && and || is __________.
  6. Converting double to int requires __________ casting.
  7. An if inside another if is called __________ if.
  8. The default branch in switch is written as __________.
  9. The result type of int + long is __________.

Section C: Programs (Attempt Any 6 out of 7, 6 x 5 = 30 Marks)

Write medium-level Java programs using only variables, data types, operators, if-else, and switch. Avoid loops and arrays.

  1. Read marks of 3 subjects and print total, average, and result using if-else. Rule: If average >= 35 print "Pass", otherwise print "Fail".
    Sample Input: 78 65 52
    Sample Output: Total = 195, Average = 65.0, Result = Pass
  2. Read two integers and print the larger number using if-else. Sample Input: 15 22
    Sample Output: Larger = 22
  3. Read a year and print whether it is a leap year or not using if-else. Leap Rule: divisible by 400 or divisible by 4 but not by 100.
    Sample Input: 2024
    Sample Output: Leap Year
  4. Read a character and check whether it is a vowel or consonant using if-else. Sample Input: e
    Sample Output: Vowel
  5. Build a simple calculator using switch for +, -, *, / and print the result. Condition: If operator is invalid, print "Invalid Operator".
    Sample Input: 25 5 /
    Sample Output: Result = 5
  6. Read a number and check whether it is positive, negative, or zero using if-else. Sample Input: -12
    Sample Output: Negative
  7. Read day number (1-7) and print the day name using switch. Sample Input: 7
    Sample Output: Sunday
