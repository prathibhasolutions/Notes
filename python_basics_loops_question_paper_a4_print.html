Section A — Multiple Choice Questions  (10 × 1 = 10 Marks)

  1. Which keyword is used to start a condition in Python? Options:  A) if   B) then   C) switch   D) case
  2. Which keyword is used when all previous conditions are false? Options:  A) elif   B) else   C) when   D) default
  3. What is the output of print(bool(0))? Options:  A) True   B) False   C) 0   D) None
  4. What is printed?
    x = 8 if x % 2 == 0: print("Even") else: print("Odd")
    Options:  A) Odd   B) Even   C) 8   D) Error
  5. Which symbol is used as the default case in match? Options:  A) *   B) _   C) ?   D) #
  6. What is the output?
    day = 2 match day: case 1: print("Mon") case 2: print("Tue") case _: print("Other")
    Options:  A) Mon   B) Tue   C) Other   D) Error
  7. How many times will this loop run?
    i = 1 while i <= 4: i += 1
    Options:  A) 3   B) 4   C) 5   D) Infinite
  8. What is the final value of x?
    x = 1 while x < 10: x *= 2
    Options:  A) 8   B) 10   C) 16   D) 32
  9. What does break do inside a loop? Options:  A) Skips current iteration   B) Stops the loop   C) Restarts the loop   D) Does nothing
  10. What is the output?
    n = 5 if n > 7: print("A") elif n > 3: print("B") else: print("C")
    Options:  A) A   B) B   C) C   D) Error

Section C — Programs  (6 × 5 = 30 Marks)

Write complete Python programs for all questions. Use basics, if-else, match, and while loops only. Do not use nested loops.
  1. Write a program to read a number and print whether it is positive, negative, or zero using if-elif-else.
    Example: Input: -7    Output: Negative
  2. Write a program to read marks of a student and print grade using if-elif-else: A (90 and above), B (75 to 89), C (50 to 74), Fail (below 50).
    Example: Input: 82    Output: B
  3. Write a menu-driven calculator using match for choices: 1-Addition, 2-Subtraction, 3-Multiplication, 4-Division, default-Invalid choice.
    Example: Input: choice=1, a=12, b=8    Output: 20
  4. Write a program to read a positive integer n and print numbers from 1 to n using a while loop.
    Example: Input: 5    Output: 1 2 3 4 5
  5. Write a program to read a positive integer n. Using a while loop, find and print the sum of digits of n.
    Example: Input: 248    Output: 14
  6. Write a program to read a positive integer n. Using a while loop, reverse the number and print it.
    Example: Input: 12345
    Output: 54321
