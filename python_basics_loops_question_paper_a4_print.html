Section A — Multiple Choice Questions  (10 × 1 = 10 Marks)

  1. What is the output of the following code?
    x = 5 if x > 3: if x > 7: print("A") else: print("B") else: print("C")
    Options:  A) A   B) B   C) C   D) Error
  2. What is the value of x after execution?
    x = 10 x //= 3 x **= 2
    Options:  A) 9   B) 3   C) 11   D) 100
  3. What is printed?
    n = 12 match n % 5: case 0: print("zero") case 1 | 2: print("small") case _: print("other")
    Options:  A) zero   B) small   C) other   D) Error
  4. How many times is Hello printed?
    i = 1 while i <= 5: if i % 2 == 0: i += 1 continue print("Hello") i += 1
    Options:  A) 5   B) 3   C) 2   D) 4
  5. What is the output?
    for i in range(2, 10, 3): print(i, end=" ")
    Options:  A) 2 5 8   B) 2 4 6 8   C) 2 3 4 5   D) 2 5 8 11
  6. What is printed?
    s = 0 for i in range(1, 6): s += i else: s += 10 print(s)
    Options:  A) 15   B) 25   C) 10   D) 16
  7. What does this code print?
    x = 7 if x > 10: print("big") elif x > 5: print("medium") elif x > 3: print("small") else: print("tiny")
    Options:  A) big   B) medium   C) small   D) tiny
  8. What is the final value printed by count?
    count = 0 n = 100 while n > 1: n //= 2 count += 1 print(count)
    Options:  A) 6   B) 7   C) 5   D) 8
  9. What is the output?
    x = "5" y = int(x) + 2 print(type(y))
    Options:  A) <class 'str'>   B) <class 'int'>   C) <class 'float'>   D) Error
  10. What is the output?
    for i in range(5): if i == 3: break else: print("done") print("end")
    Options:  A) done end   B) end   C) done   D) Error

Section C — Programs  (Answer Any 5 — 5 × 6 = 30 Marks)

Write complete Python programs. Answer any 5 questions. No nested loops are needed.
  1. Read a positive integer n. Using a for loop, print all numbers from 1 to n that are divisible by 3 or 5, but not by both. Use if/elif/else inside the loop.
    Example: Input: 20
    Output: 3 5 6 9 10 12 18 20
  2. Read a positive integer n. Using a while loop and arithmetic operators only, reverse the digits of n and print the result.
    Example: Input: 12345
    Output: 54321
  3. Read a positive integer n greater than 1. Using a for loop, determine whether n is prime or not. Print Prime or Not Prime.
    Example: Input: 17  Output: Prime      Input: 15  Output: Not Prime
  4. Read a month number m (1–12). Using a match statement, print the season:
    12, 1, 2 → Winter 3, 4, 5 → Spring 6, 7, 8 → Summer 9, 10, 11 → Autumn
    Example: Input: 7  Output: Summer
  5. Read a positive integer n. Using a for loop, print the complete multiplication table of n from 1 to 10 in the format shown.
    Example: Input: 5
    Output: 5 x 1 = 5
               5 x 2 = 10
               ...
               5 x 10 = 50
  6. Read a positive integer n. Using a while loop and arithmetic operators only, repeatedly replace n with the sum of its digits until a single digit remains. Print that final single digit.
    Example: Input: 9875  Output: 2   (9875 → 29 → 11 → 2)
