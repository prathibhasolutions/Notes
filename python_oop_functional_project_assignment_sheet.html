Project Description

1. Project Topic

The project is called a Library Management System. It manages books, members (people who borrow books), and a librarian (the person who manages the library) inside one running program.

  • Books are represented as objects with a title, author, price, and borrow status.
  • Members and the Librarian are modeled using classes that share a common parent.
  • The Library class holds and organizes everything together.

2. Project Goals

This project shows how a small but complete Python application is designed using clean, reusable, object-oriented code combined with functional-style data processing.

  • Register members and a librarian as real objects.
  • Add books to the library and track whether they are borrowed.
  • Let members borrow and return books through methods.
  • Use pure functions and higher-order functions to analyze the book collection.
  • Save and load the entire book collection using a JSON file as a simple database.
  • Run everything through a simple text menu that the user interacts with.

3. File Handling as Database

The program uses a JSON file to permanently store book records. Every book is converted into a dictionary and written to a file, and can be read back later so data is not lost when the program closes.

def save_to_file(self, filename):
    data = [book.to_dict() for book in self.books]
    with open(filename, "w") as f:
        json.dump(data, f, indent=4)

def load_from_file(self, filename):
    with open(filename, "r") as f:
        data = json.load(f)

OOP Concepts Used

4. Classes and Objects

A class is a blueprint; an object is a real instance built from that blueprint. Person, Member, Librarian, Book, and Library are all classes in this project. Each Book you create is a separate object with its own title and price.

class Book:
    def __init__(self, book_id, title, author, price):
        self.book_id = book_id
        self.title = title
        self.author = author
        self.price = price
        self._is_borrowed = False

5. Encapsulation

Encapsulation keeps important data protected inside an object. Attributes are marked private with an underscore and are only changed through controlled methods or properties, such as the age setter that blocks negative values.

class Person:
    def __init__(self, person_id, name, email, age):
        self._person_id = person_id
        self._name = name
        self._email = email
        self._age = age

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value < 0:
            raise ValueError("Age cannot be negative")
        self._age = value

6. Inheritance

Member is created as a special form of the Person class. It reuses everything Person already has (name, email, age) and adds its own extra features, like a list of borrowed books.

class Member(Person, LibraryUser):
    def __init__(self, person_id, name, email, age, member_id):
        super().__init__(person_id, name, email, age)
        self._member_id = member_id
        self._borrowed_books = []

    @property
    def member_id(self):
        return self._member_id

7. Multiple Inheritance

Librarian inherits from more than one class at once: Person (for name/email/age), LibraryUser (for the abstract role methods), and AuditLogMixin (for logging every action the librarian performs).

class AuditLogMixin:
    def __init__(self):
        self._audit_log = []

    def log_event(self, message):
        self._audit_log.append(message)

class Librarian(Person, LibraryUser, AuditLogMixin):
    def __init__(self, person_id, name, email, age, staff_id):
        Person.__init__(self, person_id, name, email, age)
        AuditLogMixin.__init__(self)
        self._staff_id = staff_id

8. Abstraction

The LibraryUser class is an abstract base class built with Python's abc module. It cannot be created directly — it only defines what every user type must be able to do, hiding how each one actually does it.

from abc import ABC, abstractmethod

class LibraryUser(ABC):
    @abstractmethod
    def get_role(self):
        pass

    @abstractmethod
    def get_details(self):
        pass

9. Magic Methods

Special double-underscore methods let custom objects behave like Python's built-in types. Here Book defines how it prints itself, and Library defines its own length and looping behavior.

class Book:
    def __str__(self):
        status = "Borrowed" if self._is_borrowed else "Available"
        return f"{self.title} by {self.author} - {status}"

class Library:
    def __len__(self):
        return len(self.books)

    def __iter__(self):
        return iter(self.books)

Functional Programming Concepts

11. Pure Functions

A pure function always gives the same output for the same input and does not change anything outside itself. These small, predictable functions are the building blocks of functional programming.

def get_title(book):
    return book.title

def get_price(book):
    return book.price

def is_available(book):
    return not book.is_borrowed

12. Functions as First-Class Objects & Higher-Order Functions

In Python, a function can be stored, passed around, and given to another function just like any value. A higher-order function is a function that accepts another function as one of its arguments and calls it internally.

def apply_to_all_books(book_list, action):
    """Takes a function 'action' and applies it to every book."""
    results = []
    for book in book_list:
        results.append(action(book))
    return results

def select_books(book_list, condition):
    """Takes a function 'condition' and keeps only books that pass it."""
    selected = []
    for book in book_list:
        if condition(book):
            selected.append(book)
    return selected

13. Function Composition

Function composition means combining two simple functions to build a new, more powerful function. Here, a discount function and a tax function are joined together into one final-price function.

def apply_discount(price):
    return price - (price * 0.10)

def add_service_tax(price):
    return price + (price * 0.05)

def compose(first_function, second_function):
    """Combines two functions into one new function."""
    def combined_function(value):
        return second_function(first_function(value))
    return combined_function

calculate_final_price = compose(apply_discount, add_service_tax)

14. Recursion

A recursive function is a function that calls itself with a smaller version of the problem until it reaches a simple base case. Here, recursion is used to add up the price of every book in the library.

def calculate_total_price(book_list):
    if len(book_list) == 0:
        return 0
    first_book = book_list[0]
    remaining_books = book_list[1:]
    return first_book.price + calculate_total_price(remaining_books)

"""
LIBRARY MANAGEMENT SYSTEM
A Beginner Python Project using OOP and Functional Programming
"""

import json
from abc import ABC, abstractmethod


# ---------------- ABSTRACTION ----------------
class LibraryUser(ABC):
    """Abstract base class - defines what every user type must do."""

    @abstractmethod
    def get_role(self):
        pass

    @abstractmethod
    def get_details(self):
        pass


# ---------------- ENCAPSULATION (Base Class) ----------------
class Person:
    def __init__(self, person_id, name, email, age):
        self._person_id = person_id
        self._name = name
        self._email = email
        self._age = age

    @property
    def name(self):
        return self._name

    @property
    def person_id(self):
        return self._person_id

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value < 0:
            raise ValueError("Age cannot be negative")
        self._age = value

    def get_contact_info(self):
        return f"{self._name} <{self._email}>"


# ---------------- MULTIPLE INHERITANCE (Mixin) ----------------
class AuditLogMixin:
    def __init__(self):
        self._audit_log = []

    def log_event(self, message):
        self._audit_log.append(message)

    def show_log(self):
        for entry in self._audit_log:
            print("LOG:", entry)


# ---------------- INHERITANCE ----------------
class Member(Person, LibraryUser):
    def __init__(self, person_id, name, email, age, member_id):
        super().__init__(person_id, name, email, age)
        self._member_id = member_id
        self._borrowed_books = []

    @property
    def member_id(self):
        return self._member_id

    def get_role(self):
        return "Member"

    def get_details(self):
        return f"Member: {self._name} (ID: {self._member_id})"

    def borrow_book(self, book):
        if book.is_borrowed:
            print(f"{book.title} is already borrowed.")
            return
        self._borrowed_books.append(book)
        book.mark_borrowed()
        print(f"{self._name} borrowed '{book.title}'")

    def return_book(self, book):
        if book in self._borrowed_books:
            self._borrowed_books.remove(book)
            book.mark_returned()
            print(f"{self._name} returned '{book.title}'")

    def list_borrowed_books(self):
        return [book.title for book in self._borrowed_books]

    def __str__(self):
        return f"Member({self._name}, ID={self._member_id})"


# ---------------- MULTIPLE INHERITANCE (used) ----------------
class Librarian(Person, LibraryUser, AuditLogMixin):
    def __init__(self, person_id, name, email, age, staff_id):
        Person.__init__(self, person_id, name, email, age)
        AuditLogMixin.__init__(self)
        self._staff_id = staff_id

    def get_role(self):
        return "Librarian"

    def get_details(self):
        return f"Librarian: {self._name} (Staff ID: {self._staff_id})"

    def add_book_to_library(self, library, book):
        library.add_book(book)
        self.log_event(f"Added book: {book.title}")
        print(f"Book '{book.title}' added by {self._name}")

    def __str__(self):
        return f"Librarian({self._name}, Staff ID={self._staff_id})"


# ---------------- MAGIC METHODS ----------------
class Book:
    def __init__(self, book_id, title, author, price):
        self.book_id = book_id
        self.title = title
        self.author = author
        self.price = price
        self._is_borrowed = False

    def mark_borrowed(self):
        self._is_borrowed = True

    def mark_returned(self):
        self._is_borrowed = False

    @property
    def is_borrowed(self):
        return self._is_borrowed

    def __str__(self):
        status = "Borrowed" if self._is_borrowed else "Available"
        return f"{self.title} by {self.author} - Rs.{self.price} - {status}"

    def __repr__(self):
        return f"Book(id={self.book_id}, title='{self.title}')"

    def to_dict(self):
        return {
            "book_id": self.book_id,
            "title": self.title,
            "author": self.author,
            "price": self.price,
            "is_borrowed": self._is_borrowed
        }


# ---------------- PURE FUNCTIONS ----------------
def get_title(book):
    return book.title


def get_price(book):
    return book.price


def is_available(book):
    return not book.is_borrowed


def is_borrowed_book(book):
    return book.is_borrowed


# ---------------- HIGHER-ORDER FUNCTIONS ----------------
def apply_to_all_books(book_list, action):
    """Takes a function 'action' and applies it to every book in the list."""
    results = []
    for book in book_list:
        results.append(action(book))
    return results


def select_books(book_list, condition):
    """Takes a function 'condition' and keeps only the books that pass it."""
    selected = []
    for book in book_list:
        if condition(book):
            selected.append(book)
    return selected


# ---------------- FUNCTION COMPOSITION ----------------
def apply_discount(price):
    """Reduces a price by 10%."""
    return price - (price * 0.10)


def add_service_tax(price):
    """Adds 5% service tax to a price."""
    return price + (price * 0.05)


def compose(first_function, second_function):
    """Combines two functions into one new function."""
    def combined_function(value):
        return second_function(first_function(value))
    return combined_function


calculate_final_price = compose(apply_discount, add_service_tax)


# ---------------- RECURSION ----------------
def calculate_total_price(book_list):
    """Recursive function: calls itself with a smaller list each time."""
    if len(book_list) == 0:
        return 0
    first_book = book_list[0]
    remaining_books = book_list[1:]
    return first_book.price + calculate_total_price(remaining_books)


# ---------------- COMPOSITION AND AGGREGATION ----------------
class Library:
    def __init__(self, name):
        self.name = name
        self.books = []
        self.members = []
        self.librarians = []

    def add_book(self, book):
        self.books.append(book)

    def add_member(self, member):
        self.members.append(member)

    def add_librarian(self, librarian):
        self.librarians.append(librarian)

    def find_book(self, title):
        for book in self.books:
            if book.title.lower() == title.lower():
                return book
        return None

    def find_member(self, member_id):
        for member in self.members:
            if member.member_id == member_id:
                return member
        return None

    # ---- FUNCTIONAL PROGRAMMING METHODS ----
    def available_books(self):
        return select_books(self.books, is_available)

    def borrowed_books(self):
        return select_books(self.books, is_borrowed_book)

    def book_titles(self):
        return apply_to_all_books(self.books, get_title)

    def sorted_books_by_price(self):
        return sorted(self.books, key=get_price)

    def total_inventory_value(self):
        return calculate_total_price(self.books)

    def expensive_books(self, limit):
        def is_expensive(book):
            return book.price >= limit
        return select_books(self.books, is_expensive)

    # ---- MAGIC METHODS ----
    def __len__(self):
        return len(self.books)

    def __iter__(self):
        return iter(self.books)

    def __str__(self):
        return f"Library({self.name}, {len(self.books)} books)"

    # ---- FILE HANDLING (JSON DATABASE) ----
    def save_to_file(self, filename):
        data = [book.to_dict() for book in self.books]
        with open(filename, "w") as f:
            json.dump(data, f, indent=4)
        print(f"Saved {len(data)} books to {filename}")

    def load_from_file(self, filename):
        try:
            with open(filename, "r") as f:
                data = json.load(f)
        except FileNotFoundError:
            print("No saved file found.")
            return
        self.books = []
        for item in data:
            book = Book(item["book_id"], item["title"], item["author"], item["price"])
            if item["is_borrowed"]:
                book.mark_borrowed()
            self.books.append(book)
        print(f"Loaded {len(self.books)} books from {filename}")


def print_menu():
    print("\n===== LIBRARY MANAGEMENT SYSTEM =====")
    print("1. Add a new book")
    print("2. Add a new member")
    print("3. Show all books")
    print("4. Show available books")
    print("5. Show borrowed books")
    print("6. Show books sorted by price")
    print("7. Show total inventory value (recursion)")
    print("8. Show final price of a book (discount + tax)")
    print("9. Borrow a book")
    print("10. Return a book")
    print("11. Save library to file")
    print("12. Load library from file")
    print("13. Exit")


def main():
    library = Library("City Central Library")

    librarian = Librarian(1, "Mr. Ravi Kumar", "ravi@library.com", 35, "STF001")
    library.add_librarian(librarian)

    book_id_counter = 1
    member_id_counter = 1

    while True:
        print_menu()
        choice = input("Enter your choice: ")

        if choice == "1":
            title = input("Enter book title: ")
            author = input("Enter author name: ")
            price = float(input("Enter book price: "))
            book = Book(book_id_counter, title, author, price)
            librarian.add_book_to_library(library, book)
            book_id_counter += 1

        elif choice == "2":
            name = input("Enter member name: ")
            email = input("Enter member email: ")
            age = int(input("Enter member age: "))
            member = Member(member_id_counter, name, email, age, f"MEM{member_id_counter:03d}")
            library.add_member(member)
            print(f"Member added: {member}")
            member_id_counter += 1

        elif choice == "3":
            print(f"\nTotal books in library: {len(library)}")
            for book in library:
                print(book)

        elif choice == "4":
            print("\nAvailable books:")
            for book in library.available_books():
                print(book)

        elif choice == "5":
            print("\nBorrowed books:")
            for book in library.borrowed_books():
                print(book)

        elif choice == "6":
            print("\nBooks sorted by price:")
            for book in library.sorted_books_by_price():
                print(book)

        elif choice == "7":
            total = library.total_inventory_value()
            print(f"\nTotal inventory value (recursion): Rs.{total}")

        elif choice == "8":
            title = input("Enter book title: ")
            book = library.find_book(title)
            if book:
                final_price = calculate_final_price(book.price)
                print(f"Original price: Rs.{book.price}")
                print(f"Final price after discount and tax: Rs.{round(final_price, 2)}")
            else:
                print("Book not found.")

        elif choice == "9":
            if not library.members:
                print("No members yet. Add a member first.")
                continue
            title = input("Enter book title to borrow: ")
            member_id = input("Enter member ID (e.g. MEM001): ")
            book = library.find_book(title)
            member = library.find_member(member_id)
            if book and member:
                member.borrow_book(book)
            else:
                print("Book or member not found.")

        elif choice == "10":
            title = input("Enter book title to return: ")
            member_id = input("Enter member ID: ")
            book = library.find_book(title)
            member = library.find_member(member_id)
            if book and member:
                member.return_book(book)
            else:
                print("Book or member not found.")

        elif choice == "11":
            library.save_to_file("library_data.json")

        elif choice == "12":
            library.load_from_file("library_data.json")

        elif choice == "13":
            print("Thank you for using the Library Management System!")
            break

        else:
            print("Invalid choice. Try again.")


if __name__ == "__main__":
    main()
