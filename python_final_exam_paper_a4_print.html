Section A: Multiple Choice Questions (10 x 1 = 10 Marks)

  1. What is the output of the following code? num = 7 if num % 2 == 0: print("Even") else: print("Odd") A) Even B) Odd C) Error D) 7
  2. What is the output of the following code? day = 3 match day: case 1: print("Mon") case 2: print("Tue") case 3: print("Wed") case _: print("Invalid") A) Mon B) Tue C) Wed D) Invalid
  3. What is the output of the following code? i = 1 while i <= 5: print(i, end=" ") i += 2 A) 1 2 3 4 5 B) 1 3 5 C) 2 4 D) 1 2 3
  4. What is the output of the following code? def add(a, b): return a + b print(add(3, 7)) A) 37 B) 10 C) (3, 7) D) Error
  5. What is the output of the following code? text = "Hello" count = 0 for ch in text: if ch in "aeiou": count += 1 print(count) A) 5 B) 2 C) 3 D) 1
  6. What does the mode "w" do when opening an existing file? A) Reads the file B) Overwrites the content C) Appends to the content D) Creates a new folder
  7. What is the output of the following code? n = 4 fact = 1 i = 1 while i <= n: fact *= i i += 1 print(fact) A) 24 B) 120 C) 10 D) 4
  8. Which keyword is used to define a function in Python? A) function B) func C) def D) define
  9. What is the output of the following code? num = 1234 rev = 0 while num > 0: rev = rev * 10 + num % 10 num //= 10 print(rev) A) 1234 B) 4321 C) 1243 D) 4231
  10. What is the output of the following code? light = "Red" match light: case "Red": print("Stop") case "Yellow": print("Slow Down") case "Green": print("Go") case _: print("Invalid") A) Go B) Slow Down C) Stop D) Invalid
