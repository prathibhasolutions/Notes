Section A — Multiple Choice Questions  (10 × 1 = 10 Marks)

  1. What is the output of the following code?
    int x = 5; if (x > 3) { if (x > 7) System.out.println("A"); else System.out.println("B"); } else { System.out.println("C"); }
    Options:  A) A   B) B   C) C   D) Error
  2. What is the value of x after execution?
    int x = 10; x /= 3; x *= x;
    Options:  A) 9   B) 3   C) 11   D) 100
  3. What is printed?
    int n = 12; switch (n % 5) { case 0: System.out.println("zero"); break; case 1: case 2: System.out.println("small"); break; default: System.out.println("other"); }
    Options:  A) zero   B) small   C) other   D) Error
  4. How many times is Hello printed?
    int i = 1; while (i <= 5) { if (i % 2 == 0) { i++; continue; } System.out.println("Hello"); i++; }
    Options:  A) 5   B) 3   C) 2   D) 4
  5. What is the output?
    for (int i = 2; i < 10; i += 3) System.out.print(i + " ");
    Options:  A) 2 5 8   B) 2 4 6 8   C) 2 3 5 8   D) 2 5 8 11
  6. What is printed?
    int s = 0; for (int i = 1; i <= 5; i++) s += i; System.out.println(s + 10);
    Options:  A) 15   B) 25   C) 10   D) 16
  7. What does this code print?
    int x = 7; if (x > 10) System.out.println("big"); else if (x > 5) System.out.println("medium"); else if (x > 3) System.out.println("small"); else System.out.println("tiny");
    Options:  A) big   B) medium   C) small   D) tiny
  8. What is the value printed by count?
    int count = 0, n = 100; while (n > 1) { n /= 2; count++; } System.out.println(count);
    Options:  A) 6   B) 7   C) 5   D) 8
  9. What is the output?
    int a = 7, b = 2; double result = (double) a / b; System.out.println(result);
    Options:  A) 3   B) 3.0   C) 3.5   D) Error
  10. What is the output?
    for (int i = 0; i < 5; i++) { if (i == 3) break; } System.out.println("end");
    Options:  A) end   B) Nothing   C) 3   D) Error

Section C — Programs  (Answer Any 5 — 5 × 6 = 30 Marks)

Write complete Java programs using a class and main method. Use Scanner for input. Answer any 5 questions. No nested loops are needed.
  1. Read a positive integer n. Using a for loop, print all numbers from 1 to n that are divisible by 3 or 5, but not by both. Use if/else if/else inside the loop.
    Example: Input: 20  Output: 3 5 6 9 10 12 18 20
  2. Read a positive integer n. Using a while loop and arithmetic operators only, reverse the digits of n and print the result.
    Example: Input: 12345  Output: 54321
  3. Read a positive integer n greater than 1. Using a for loop, determine whether n is prime or not. Print Prime or Not Prime.
    Example: Input: 17  Output: Prime      Input: 15  Output: Not Prime
  4. Read a month number m (1–12). Using a switch statement, print the season:
    12, 1, 2 → Winter 3, 4, 5 → Spring 6, 7, 8 → Summer 9, 10, 11 → Autumn
    Example: Input: 7  Output: Summer
  5. Read a positive integer n. Using a for loop, print the complete multiplication table of n from 1 to 10 in the format shown.
    Example: Input: 5
    Output: 5 x 1 = 5
               5 x 2 = 10
               ...
               5 x 10 = 50
  6. Read three integers: first term a, common ratio r, and number of terms n. Using a for loop, print the first n terms of the Geometric Progression (GP) series and also print their sum.
    Example: Input: a=2, r=3, n=5
    Output: 2 6 18 54 162
               Sum = 242
