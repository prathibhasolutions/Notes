Section A: MCQ Answer Key (10 Marks)

1. B — [1, 2] [1, 2]. The default list is created once; both calls mutate the same object, so both printed references show the final state.
Common trap: students usually answer A.
2. B — [2, 2, 2]. The lambda captures the variable i, not its value; late binding makes all three read the final value 2.
3. B — AttributeError. __slots__ removes __dict__, so only the listed attributes may be set.
4. A — ['D', 'B', 'C', 'A', 'object']. C3 linearisation keeps the left base first.
5. B — True False. == compares values; is compares identity, and a joined string is not the interned literal.
6. C — 12. KeyError is a subclass of LookupError; the finally block still runs and adds 10.
7. A — [6, 8]. The walrus operator binds y inside the condition so the expression can use it.
8. B — A C B D. MRO is D, B, C, A; super() in B continues with C, which prints A first.
9. A — prints True, then TypeError. Defining __eq__ sets __hash__ = None unless __hash__ is also defined.
10. B — 0, [1, 4, 9], []. A generator is exhausted after it is fully consumed.
