Project Description

This project is a complete Python-based school management system designed for students to learn object-oriented programming, functional programming, CLI input handling, file database operations, and professional software structure.

It is a multi-file project that manages students, teachers, administrators, departments, courses, enrollments, reports, and grade information using a JSON file database layer.

Focus: Real Learning + Software Design

Main System

The system stores academy information, user data, courses, students, teachers, enrollments, and report records.

Functional Programming

The system uses list comprehensions, map/filter, reduce-style computations, sorting, and dashboard generation.

OOP Concepts

It uses classes, inheritance, abstraction, encapsulation, multiple inheritance, composition, aggregation, and magic methods.

File Handling Database

JSON files are used as a lightweight database. Data is saved and loaded in persistent storage.

  • Aggregation through Student, Course, Enrollment relationships.

        self._name = name

File Database Layer

storage.py - Lightweight JSON Database
import json
import os

class JsonFileStorage:
    def __init__(self, data_dir):
        self.data_dir = data_dir
        os.makedirs(self.data_dir, exist_ok=True)

    def save_json(self, filename, payload):
        with open(os.path.join(self.data_dir, filename), 'w') as file:
            json.dump(payload, file, indent=4)

    def load_json(self, filename):
        path = os.path.join(self.data_dir, filename)
        if not os.path.exists(path):
            return {}
        with open(path, 'r') as file:
            return json.load(file)

How the Application Works

The user launches the program using the main entry file. The application builds a School object and an object relation tree of departments, students, teachers, administrators, courses, and enrollments. User input is read from the terminal and business operations are executed through service classes.

Data persists through JSON files. Every major action saves or updates the data set so the application can be restarted and load data from the stored files.

Learning Outcome

Students who study this project learn how Python applications are organized into files, how classes model real-world objects, how services handle operations, and how storage layers separate business logic from persistence.

This study project is a complete Python educational application with OOP and functional design patterns.
