Section A: Multiple Choice Questions (10 x 1 = 10 Marks)

  1. Which symbol is used at the start of every formula in Excel? A) + B) = C) @ D) #
  2. Which function is used to calculate the total of values in a range? A) SUM B) AVERAGE C) COUNT D) PRODUCT
  3. Which formula calculates the average of cells B2 to B20? A) =SUM(B2:B20) B) =AVERAGE(B2:B20) C) =COUNT(B2:B20) D) =MIN(B2:B20)
  4. Which function adds values only when one condition is met? A) SUM B) SUMIF C) COUNT D) ROUND
  5. Which function can search for a value in the first column of a table and return a related value from another column? A) VLOOKUP B) CONCAT C) RANK D) PMT
  6. Which function adds values based on multiple criteria? A) SUMIFS B) SUM C) COUNTBLANK D) IFERROR
  7. Which feature highlights cells based on rules such as greater than a target? A) Data Validation B) Conditional Formatting C) Grouping D) Page Break
  8. Which chart is best to compare monthly sales values across several regions? A) Column chart B) Pie chart C) Scatter chart D) Surface chart
  9. Which function is used to avoid errors when a lookup value is not found? A) IFERROR B) IF C) MID D) ROUND
  10. Which tool is used to summarize and analyze large datasets quickly? A) PivotTable B) Spell Check C) Find and Replace D) Freeze Panes
