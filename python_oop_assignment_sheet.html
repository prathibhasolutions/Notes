Python Object Oriented Programming Assignment Sheet
Topic-wise Programming Practice for Python Learners
Instructions: Solve each question using Python OOP syntax only. Write the class design, source code, and a short explanation for every program. Use concepts like self, __init__, inheritance, encapsulation, polymorphism, and Python magic methods.

Topic-wise Assignment Questions

1. Class and Object Basics

  1. Create a class Student with name, roll_no, and marks.
  2. Instantiate two student objects and display their details.
  3. Create a Car class with attributes brand and speed.
  4. Create a Book class with title, author, price, and display method.

2. Constructor and Instance Variables

  1. Design an Employee class using a constructor.
  2. Create a Rectangle class with length and breadth using __init__.
  3. Write a program where each object stores a unique ID.
  4. Make a class BankAccount that initializes account number and balance.

3. Methods and Behavior

  1. Create a Circle class with methods to calculate area and circumference.
  2. Write a class Calculator with methods for add, subtract, multiply, and divide.
  3. Build a Person class with eat(), sleep(), and study().
  4. Create a LibraryBook class with methods to borrow and return a book.

4. Instance, Class, and Static Variables

  1. Create a class where a class variable counts the number of objects created.
  2. Write a class with both instance variables and class variables.
  3. Demonstrate the difference between instance attributes and class attributes.
  4. Create a Department class that stores department name as a class variable.

5. Encapsulation in Python

  1. Implement a Student class with private attributes and getter/setter methods.
  2. Write a BankAccount class that restricts direct balance modification.
  3. Create a class with a private method __calculate() and call it safely using Python name-mangling rules.
  4. Demonstrate public, protected, and private member usage in Python OOP.

6. Inheritance

  1. Create a base class Animal and derived classes Dog and Cat.
  2. Write a Vehicle base class and derive Bike and Car.
  3. Make a Person parent class and Student child class.
  4. Implement a Shape base class with Rectangle and Circle derived classes.

7. Method Overriding and super()

  1. Create a base Animal class with a sound() method and override it in derived classes.
  2. Use super() in a child constructor to initialize parent attributes.
  3. Write a program showing different behavior of the same method in different classes.
  4. Build a Teacher and Student class where child methods override a base method.

8. Multiple Inheritance

  1. Create classes Employee, Scholar, and Researcher with multiple inheritance.
  2. Design a class combining Student and SportsPlayer properties.
  3. Demonstrate MRO with a small program in Python.
  4. Create a class that inherits from two different parent classes and shows method resolution.

9. Polymorphism in Python

  1. Create a base class Shape with area() and use different derived classes.
  2. Demonstrate Python duck typing using a function that accepts any object with a move() method.
  3. Write a program showing polymorphic behavior with default arguments in Python methods.
  4. Build a Payment class with pay() implemented differently in multiple classes.

10. Abstraction

  1. Use abc and @abstractmethod to create an abstract base class.
  2. Create a Vehicle abstract class with abstract methods start() and stop().
  3. Build a framework where different devices share a common abstract interface.
  4. Show why abstract classes are useful in designing large systems.

11. Class Methods and Static Methods

  1. Create a Student class with a class method to count total students.
  2. Write a static method to check if a number is prime.
  3. Build a class with both static and class methods and explain their differences.
  4. Make a Time class with a static method to display current time information.

12. Magic Methods and Operator Overloading

  1. Create a ComplexNumber class and overload +.
  2. Implement __str__ and __repr__ for a class.
  3. Overload __len__ for a custom data class.
  4. Create a Vector class that supports addition and comparison.

13. Composition and Aggregation

  1. Create a University class containing multiple Department objects.
  2. Make a Team class that contains multiple Player objects.
  3. Build an Order class containing multiple Item objects.
  4. Show the difference between composition and aggregation using a real-life example.

14. Exception Handling in OOP

  1. Create a BankAccount class that raises an error on negative withdrawal.
  2. Write a class to validate age and throw ValueError for invalid input.
  3. Handle exceptions in methods using try, except, and finally.
  4. Build a Student class with error handling for invalid marks.

15. File Handling with OOP

  1. Create a StudentFileManager class to save and read student records.
  2. Build a class that writes employee data to a CSV or text file.
  3. Store and retrieve book records using object-oriented file operations.
  4. Develop a mini inventory system using file-backed classes.

16. Mini Projects

  1. Create a Library Management System with books, students, and issue/return functions.
  2. Build a Student Result Management System using classes for student, marks, and result.
  3. Design a Banking System with account creation, deposit, withdraw, and balance check.
  4. Create a Hospital Management System for patient records and appointments.

17. Advanced Practice Questions

  1. Design a real-world Python class hierarchy for a restaurant ordering system.
  2. Create a shopping cart using classes such as Product, CartItem, and Cart.
  3. Build a ticket booking system for movies or trains.
  4. Implement a simple quiz game using Python class-based structures.

18. Beginner Python OOP Extras

  1. Use the @property decorator to create getter and setter behavior for class attributes.
  2. Write a Python class using @classmethod and @staticmethod to compare their usage.
  3. Create a class using the @dataclass decorator and explain its advantage over regular classes.
  4. Implement a class with a custom __del__ method and explain object destruction in Python.
  5. Write a program with a nested class, such as a Student class containing an inner Address class.
  6. Create a small Python package/module design for OOP, such as separate files for student.py, course.py, and main.py, and connect them using classes.
Suggested Practice Plan: Solve the beginner questions first, then move to inheritance, abstraction, file handling, and the mini projects.
