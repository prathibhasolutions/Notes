Python OOP Syllabus Notes

1. Class and Object Basics

A class is a blueprint for creating objects. An object is an instance of a class. A class stores attributes and methods, while an object holds actual data.

  • Class defines the structure and behavior of objects.
  • Object is a real instance created from the class.
  • Attributes store data, and methods describe behavior.
class Student:
    def __init__(self, name, roll_no, marks):
        self.name = name
        self.roll_no = roll_no
        self.marks = marks

    def display(self):
        print(self.name, self.roll_no, self.marks)

s1 = Student("Asha", 101, 89)
s2 = Student("Kiran", 102, 92)
s1.display()
s2.display()

2. Constructor and Instance Variables

The __init__ method is a special constructor used to initialize object attributes. Every object gets its own instance variables.

  • __init__ runs automatically when an object is created.
  • Instance variables are stored separately for each object.
  • Constructors help assign default or incoming values to the object.
class Employee:
    def __init__(self, emp_id, name, salary):
        self.emp_id = emp_id
        self.name = name
        self.salary = salary

e1 = Employee(1, "Ravi", 45000)
print(e1.name, e1.salary)

3. Methods and Behavior

Methods define the behavior of a class. They can perform calculations, manipulate attributes, or return results.

  • Methods are functions defined inside a class.
  • They operate on object data through self.
  • Methods help implement actions like calculation, validation, or display.
class Circle:
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius * self.radius

    def circumference(self):
        return 2 * 3.14 * self.radius

c = Circle(7)
print("Area:", c.area())
print("Circumference:", c.circumference())

4. Instance, Class, and Static Variables

Instance variables are unique per object. Class variables are shared by all instances. Static variables are usually used for information that belongs to the class rather than a specific object.

  • Instance variables belong to each object individually.
  • Class variables are shared by all instances of the class.
  • Static-like class-level data is useful for common constants or counters.
class Student:
    school = "ABC Public School"
    count = 0

    def __init__(self, name):
        self.name = name
        Student.count += 1

s1 = Student("Asha")
s2 = Student("Bharat")
print(Student.school)
print(Student.count)

5. Encapsulation

Encapsulation protects data using private members and controlled access through methods. In Python, private attributes are named with double underscores.

  • Encapsulation hides internal object details from outside access.
  • Private attributes are indicated with __ in Python.
  • Getter and setter methods provide safe controlled access.
class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def deposit(self, amount):
        self.__balance += amount

    def withdraw(self, amount):
        if amount <= self.__balance:
            self.__balance -= amount
        else:
            print("Insufficient balance")

    def get_balance(self):
        return self.__balance

acc = BankAccount(5000)
acc.deposit(1000)
print(acc.get_balance())

6. Inheritance

Inheritance allows one class to extend another. The child class inherits properties and methods from the parent class.

  • Child class inherits attributes and methods from parent.
  • It promotes code reuse and better organization.
  • Parent class is called base class and child class is derived class.
class Animal:
    def speak(self):
        print("Animal speaks")

class Dog(Animal):
    def bark(self):
        print("Dog barks")

class Cat(Animal):
    def meow(self):
        print("Cat meows")

d = Dog()
d.speak()
d.bark()

7. Method Overriding and super()

Method overriding happens when a child class defines a method with the same name as its parent. The super() function lets the child call the parent method.

  • Overriding changes the parent behavior in the child class.
  • super() allows access to parent methods and constructors.
  • It is useful when child needs extra initialization or custom logic.
class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
    def __init__(self, name, roll_no):
        super().__init__(name)
        self.roll_no = roll_no

s = Student("Nisha", 7)
print(s.name, s.roll_no)

8. Multiple Inheritance and MRO

Multiple inheritance allows a class to inherit from more than one parent. Python resolves the method order using the Method Resolution Order (MRO).

  • Multiple inheritance uses more than one parent class.
  • MRO decides which parent method is called first.
  • It is powerful but can create ambiguity if not designed carefully.
class Employee:
    def work(self):
        print("Working")

class Scholar:
    def study(self):
        print("Studying")

class Researcher(Employee, Scholar):
    pass

r = Researcher()
r.work()
r.study()
print(Researcher.mro())

9. Polymorphism

Polymorphism means the same method name can behave differently in different classes. This is very useful for code reusability.

  • One method name can behave differently for different classes.
  • It enables common interfaces for multiple implementations.
  • Polymorphism reduces code dependency on specific class types.
class Circle:
    def area(self):
        return 3.14 * 2 * 2

class Rectangle:
    def area(self):
        return 4 * 5

for shape in [Circle(), Rectangle()]:
    print(shape.area())

10. Abstraction

Abstraction hides unnecessary implementation details and exposes only important behavior. It is implemented using abstract base classes.

  • Abstraction focuses on what an object does, not how it does it.
  • ABC and @abstractmethod define a common rule set.
  • It helps in designing stable interfaces for large systems.
from abc import ABC, abstractmethod

class Vehicle(ABC):
    @abstractmethod
    def start(self):
        pass

class Bike(Vehicle):
    def start(self):
        print("Bike started")

b = Bike()
b.start()

11. Class Methods and Static Methods

@classmethod receives the class itself as the first parameter. @staticmethod is independent and does not access instance or class state automatically.

  • @classmethod works with class-level information.
  • @staticmethod works like a normal utility function inside the class.
  • Class methods use cls, while static methods do not use self or cls.
class Student:
    count = 0

    def __init__(self, name):
        self.name = name
        Student.count += 1

    @classmethod
    def total_students(cls):
        return cls.count

    @staticmethod
    def is_prime(n):
        return all(n % i for i in range(2, int(n ** 0.5) + 1))

s1 = Student("A")
s2 = Student("B")
print(Student.total_students())
print(Student.is_prime(7))

12. Magic Methods and Operator Overloading

Magic methods define special behavior for built-in operators and object representations. They start and end with double underscores.

  • Magic methods are special dunder methods like __str__ and __add__.
  • They allow custom behavior for operators and object display.
  • Operator overloading makes user-defined objects work naturally with Python syntax.
class ComplexNumber:
    def __init__(self, real, imag):
        self.real = real
        self.imag = imag

    def __add__(self, other):
        return ComplexNumber(self.real + other.real, self.imag + other.imag)

    def __str__(self):
        return f"{self.real}+{self.imag}i"

c1 = ComplexNumber(2, 3)
c2 = ComplexNumber(4, 5)
print(c1 + c2)
print(str(c1))

13. Composition and Aggregation

Composition is a strong ownership relation where a part belongs entirely to the whole. Aggregation is a weaker relation where the object may exist independently.

  • Composition means one object owns or contains another.
  • Aggregation means one object uses another without owning it completely.
  • These patterns model real-world relationships between systems.
class Player:
    def __init__(self, name):
        self.name = name

class Team:
    def __init__(self):
        self.players = []

    def add_player(self, player):
        self.players.append(player)

team = Team()
team.add_player(Player("Rohit"))
team.add_player(Player("Virat"))
print(len(team.players))

14. Exception Handling in OOP

OOP programs can raise custom or built-in exceptions. Exception handling ensures the program remains safe and user-friendly.

  • Exceptions represent runtime errors and invalid conditions.
  • try, except, and finally control error flow.
  • Exception handling keeps class methods robust during invalid inputs.
class BankAccount:
    def __init__(self, balance):
        self.balance = balance

    def withdraw(self, amount):
        try:
            if amount > self.balance:
                raise ValueError("Withdraw amount exceeds balance")
            self.balance -= amount
        except ValueError as e:
            print(e)

acc = BankAccount(500)
acc.withdraw(600)

15. File Handling with OOP

Classes may be used to manage file inputs and outputs. The file is treated as a storage layer or record set for objects.

  • OOP classes can encapsulate all file read and write logic.
  • File-handling methods manage persistent storage of object data.
  • This pattern is useful for records, inventory, and student management systems.
class StudentFileManager:
    def save(self, student):
        with open("students.txt", "a") as f:
            f.write(student + "\n")

    def read(self):
        with open("students.txt", "r") as f:
            return f.read()

m = StudentFileManager()
m.save("Asha")
print(m.read())

16. Relationship Modeling in OOP

Real-world software design often uses relationships such as one-to-many, ownership, or dependency. These are modeled using class composition, aggregation, and object interaction patterns.

  • Relationships show how objects interact in software design.
  • Composition and aggregation are common relationship patterns.
  • These patterns help describe ownership, dependency, and teamwork between objects.
class Department:
    def __init__(self, name):
        self.name = name

class University:
    def __init__(self):
        self.departments = []

    def add_department(self, dept):
        self.departments.append(dept)

u = University()
u.add_department(Department("Computer Science"))
print(len(u.departments))

17. Advanced Practice Concepts

These include @property, @dataclass, nested classes, and package-based module design. They are used for cleaner and more professional software structure.

  • @property allows controlled read and write of attributes.
  • @dataclass reduces boilerplate for simple data classes.
  • Nested classes and packages help structure larger Python applications elegantly.
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    marks: int

s = Student("Meera", 90)
print(s)
