Section A: Multiple Choice Questions (10 x 1 = 10 Marks)

  1. What is the datatype of the result when an integer is added to a float in Python? A) <class 'int'> B) <class 'float'> C) <class 'complex'> D) Error
  2. Which statement is valid multiple assignment syntax in Python? A) x, y = 10 20 B) x = y = 10 C) int x, y = 10, 20 D) x := 10, y := 20
  3. What is the value of floor division of 5 by 2 plus remainder of 5 divided by 2? A) 1 B) 2 C) 3 D) 4
  4. Which expression uses a bitwise operator? A) a and b B) a & b C) a in b D) a is b
  5. Which pair correctly represents the boolean value of a non-empty string and the number zero? A) False False B) True False C) False True D) True True
  6. If 101 and 11 are treated as binary values and converted to decimal, what is their sum? A) 6 B) 7 C) 8 D) 9
  7. What is the output when the text Py is repeated two times and then 3 is concatenated as text? A) PyPy3 B) Py23 C) PyPyPy D) Error
  8. What substring is obtained from the word python using indices from minus four to minus one? A) tho B) hon C) yth D) thon
  9. Which operator checks whether two variables point to the same object? A) == B) = C) is D) in
  10. What is the value of 3 raised to the power of 2 raised to the power of 2 in Python? A) 81 B) 36 C) 18 D) 12

Section B: Fill In The Blanks (10 x 1 = 10 Marks)

  1. The operator used for exponentiation in Python is __________.
  2. The datatype of a number written with j as imaginary part is __________.
  3. After converting a number into text form, the datatype becomes __________.
  4. Division of two integers using the normal division operator gives a __________ type result.
  5. In Python, an identifier cannot start with a __________.
  6. The boolean value of an empty string is __________.
  7. Joining two strings with plus operator is called string __________.
  8. Floor division of 17 by 3 gives __________.
  9. The cast used to convert a float value to integer is __________.
  10. Negative index minus one in a string refers to the __________ character.

Section C: Programs (6 x 5 = 30 Marks)

Write programs using only syntax, datatypes, variables, operators, numbers, casting, booleans, and strings. Do not use loops or if/else. Keep exactly two formula-based programs.

  1. Write a program to read the radius of a circle and print diameter, circumference, and area using standard formulas.
  2. Write a program to read a string and print first character, last character, first three characters, last three characters, reverse string, length, uppercase form, and lowercase form.
  3. Write a program to read first name and last name and print full name, full name in uppercase, full name in title case, initials, and total number of characters excluding spaces.
  4. Write a program to read two numbers and print the boolean results for greater than, less than, equal to, not equal to, greater than or equal to, less than or equal to, and boolean conversion of each number.
  5. Write a program to read three numbers and print sum, difference, product, division, floor division, remainder, power, and the datatype of each computed result.
  6. Write a program to read principal, rate, and time, then print simple interest, total amount, and monthly interest using standard formulas.
