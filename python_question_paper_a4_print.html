Section C: Programs (Answer Any 5 Questions, 5 x 6 = 30 Marks)

Write complete Python programs. Answer any 5 questions.
  1. Read an integer n. Print code 1 if n is positive-even-prime, code 2 if positive-even-non-prime, code 3 if positive-odd-prime, code 4 if positive-odd-non-prime, and code 0 if n <= 0. Use nested if only.
    Example: Input: 11
    Output: 3
  2. Read integer n. Compute
    S = (1*1) - (1*2) + (2*1) - (2*2) + (3*1) - (3*2) + ... + (n*1) - (n*2)
    using nested loops and print S. No formula shortcuts.
    Example: Input: 3
    Output: -6
  3. Read integer n. Using while loop and arithmetic operations only, repeatedly replace n by sum of its digits until a single digit remains. Print that final digit.
    Example: Input: 9875
    Output: 2
  4. Read integer r (1 <= r <= 9). Print the first r rows of Pascal triangle using nested loops only. Do not use arrays or strings. Each row must appear on a new line with values separated by a single space.
    Example: Input: 5
    Output:
    1
    1 1
    1 2 1
    1 3 3 1
    1 4 6 4 1
  5. Read integer t. Find the smallest positive integer k such that
    1^2 + 2^2 + 3^2 + ... + k^2 >= t
    using loop only. Print k and the achieved sum.
    Example: Input: 20
    Output: 4 30
  6. Read integer n. Count how many digits of n are even, odd, and zero (treat input 0 carefully). Print these three counts in order. Use loops and operators only.
    Example: Input: 2461350
    Output: 3 3 1
  7. Read integer n. Check whether n belongs to the Fibonacci series or not using loops and variables only. Print YES if it belongs to the series and NO otherwise. Treat 0 and 1 correctly.
    Example: Input: 34
    Output: YES
