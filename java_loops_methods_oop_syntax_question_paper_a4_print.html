Section C: Programs (Attempt Any 6 out of 7, 6 x 5 = 30 Marks)

Write moderately challenging Java programs with correct syntax. Focus on loops, nested loops, methods, and basic OOP syntax.

  1. Write a program using for loop to print Fibonacci series for n terms and also print the sum of even-valued terms. Sample Input: 7
    Sample Output: 0 1 1 2 3 5 8, Even Sum = 10
  2. Write a program using while loop to print all prime numbers between m and n (inclusive) and print total prime count. Sample Input: 10 30
    Sample Output: 11 13 17 19 23 29, Count = 6

    Sample Output:
    *****
    * *

    * *
    *****

    Sample Output: Total = 251, Percentage = 83.67, Grade = A
