Section A — Multiple Choice Questions  (10 × 1 = 10 Marks)

  1. What is the output of the following code? int x = 17, y = 5; printf("%d %d", x / y, x % y); A) 3 2   B) 3.4 2   C) 3 3   D) Error
  2. What does the following code print? int a = 15; if (a % 3 == 0 && a % 5 == 0) printf("FizzBuzz"); else if (a % 3 == 0) printf("Fizz"); else if (a % 5 == 0) printf("Buzz"); else printf("None"); A) Fizz   B) Buzz   C) FizzBuzz   D) None
  3. What is the output? (observe missing break) int n = 2; switch(n) { case 1: printf("one "); case 2: printf("two "); case 3: printf("three "); default: printf("done"); } A) two   B) two three   C) two three done   D) one two three done
  4. What is the value printed? int i = 1, sum = 0; while (i <= 5) { if (i % 2 != 0) sum += i; i++; } printf("%d", sum); A) 15   B) 9   C) 6   D) 8
  5. What is the value of s? int s = 0; for (int i = 10; i >= 1; i -= 3) s += i; printf("%d", s); A) 19   B) 25   C) 22   D) 28
  6. What is printed? int x = 1; while (x < 100) x *= 3; printf("%d", x); A) 81   B) 100   C) 243   D) 27
  7. What does this loop print? for (int i = 1; i <= 6; i++) { if (i % 2 == 0) continue; printf("%d ", i); } A) 2 4 6   B) 1 2 3 4 5 6   C) 1 3 5   D) 1 3 5 6
  8. What is the value of 5 > 3 && 2 < 4 || 0 in C? A) 0   B) 2   C) 1   D) Compilation Error
  9. What is output? int n = 25; if (n > 0 && n % 5 == 0) if (n > 20) printf("A"); else printf("B"); else printf("C"); A) A   B) B   C) C   D) AB
  10. How many times is Hi printed? for (int i = 0; i < 10; i++) { if (i % 3 == 0) continue; if (i == 7) break; printf("Hi\n"); } A) 10   B) 6   C) 5   D) 4

Section C — Programs  (Attempt Any 5 — 5 × 6 = 30 Marks)

Write complete C programs with #include <stdio.h> and main(). Attempt any 5.
  1. if / else Read three sides a, b, c of a triangle (positive integers). First check whether they can form a valid triangle (sum of any two sides must be greater than the third side). If not valid, print Not a Triangle. If valid, classify and print:
    • Equilateral — all three sides equal
    • Isosceles — exactly two sides equal
    • Scalene — all sides different
    Use only if / else if / else (no loops needed). Sample 1 — Input: 5 5 5   Output: Valid Triangle - Equilateral
    Sample 2 — Input: 5 5 8   Output: Valid Triangle - Isosceles
    Sample 3 — Input: 3 4 5   Output: Valid Triangle - Scalene
    Sample 4 — Input: 1 2 10  Output: Not a Triangle
  2. switch Read a day number d (1–7, where 1 = Monday). Using a switch statement, print the full name of the day. Also print whether it is a Weekday (Mon–Fri) or a Weekend (Sat, Sun). For any number outside 1–7, print Invalid day number. Sample 1 — Input: 3  Output: Wednesday - Weekday
    Sample 2 — Input: 6  Output: Saturday - Weekend
    Sample 3 — Input: 9  Output: Invalid day number
  3. while Read two positive integers a and b. Using a while loop, find their GCD (Greatest Common Divisor) using the Euclidean algorithm: repeatedly replace the larger number with the remainder of dividing the larger by the smaller, until the remainder is zero. Print the GCD and also compute and print the LCM using the formula LCM = (a * b) / GCD. Sample 1 — Input: 48 18  Output: GCD = 6, LCM = 144
    Sample 2 — Input: 100 75  Output: GCD = 25, LCM = 300
  4. while Read a positive integer n. Using a while loop and arithmetic operators only, check whether n is a perfect number. A perfect number equals the sum of all its proper divisors (divisors excluding itself). Print Perfect or Not Perfect. Also print the list of proper divisors found. Sample 1 — Input: 6   Output: Divisors: 1 2 3   Sum = 6   Perfect
    Sample 2 — Input: 12  Output: Divisors: 1 2 3 4 6   Sum = 16   Not Perfect
  5. for Read a positive integer n. Using a single for loop, compute and print the sum of squares series: S = 1² + 2² + 3² + ... + n² Print each term on the same line separated by +, then print the final sum on the next line. Sample 1 — Input: 5
    Output: 1 + 4 + 9 + 16 + 25 = 55
    Sample 2 — Input: 3
    Output: 1 + 4 + 9 = 14
  6. for Read three integers: first term a, common ratio r, and number of terms n. Using a single for loop, print the first n terms of the Geometric Progression (GP) series. Also compute and print the sum of the series. Do not use pow(); multiply term by r in each iteration. Sample 1 — Input: a=2 r=3 n=5
    Output: 2 6 18 54 162   Sum = 242
    Sample 2 — Input: a=5 r=2 n=4
    Output: 5 10 20 40   Sum = 75
