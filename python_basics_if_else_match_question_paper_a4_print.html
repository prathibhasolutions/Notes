Python Part 1 -Question Paper

Instructions: Answer all questions. Section A has 10 MCQs, Section B has 10 fill in the blanks, and Section C has 6 programs. Section A: Multiple Choice Questions (10 x 1 = 10 Marks)

  1. What is the output of: print(bool([]), bool('0'))? A) False False B) True False C) False True D) True True
  2. Which expression is equivalent to not (a and b)? A) not a and not b B) not a or not b C) a and not b D) a or b
  3. If x = 5, what is printed by print('A' if x % 2 else 'B')? A) A B) B C) 5 D) Error
  4. What is the output of print(3 == 3.0, 3 is 3.0)? A) True True B) False False C) True False D) False True
  5. Which statement about match-case is correct? A) It supports guard clauses using if B) It works only with int/str C) It requires default keyword D) It checks object identity only
  6. What is the output of print(7 // -3, 7 % -3)? A) -2 1 B) -3 -2 C) -3 2 D) -2 -1
  7. Which option correctly identifies Python's default case pattern in match? A) default: B) else: C) case _: D) case *:
  8. For s = 'Python', what does s[-4:-1] return? A) tho B) yth C) ytho D) ythn
  9. If n = 0, which condition is safest to check "non-zero"? A) if n == True B) if bool(n) is True C) if n D) if n is not False
  10. What is printed by print(not True or False and True)? A) True B) False C) None D) Error

Section B: Fill In The Blanks (10 x 1 = 10 Marks)

  1. The operator with higher precedence between and and or is __________.
  2. In match-case, a condition added to a pattern is called a __________.
  3. The result of bool('') is __________.
  4. The result of bool('False') is __________.
  5. The equality operator is __________, while identity operator is __________.
  6. The output type of 9 / 3 is __________.
  7. The value of 7 // -3 is __________.
  8. The wildcard/default pattern in match is __________.
  9. The slice 'Python'[-3:] gives __________.
  10. The expression not (False or True) evaluates to __________.

Section C: Programs (6 x 5 = 30 Marks)

Write clear and complete programs on the given topics. Use if-else and match where requested. Keep logic correct for edge cases and tricky values.

  1. Formula-based: Write a program to read length and breadth of a rectangle and print area and perimeter. Validate that both values are positive; otherwise print Invalid dimensions.
    Example Input: length = 7, breadth = 4
    Example Output: Area = 28, Perimeter = 22
  2. If-else based: Write a program to read three numbers and print the greatest number. Handle ties clearly: if exactly two are equal and greatest, print both values and mention tie.
    Example Input: a = 9, b = 9, c = 3
    Example Output: Greatest values are 9 and 9 (tie)
  3. If-else based: Write a program to read a year and print whether it is a leap year or not using full Gregorian rules. Also reject year values less than 1.
    Example Input: year = 1900
    Example Output: 1900 is not a leap year
  4. If-else based: Write a program to read marks in five subjects, calculate total and percentage, then print grade as Distinction, First Class, Second Class, Pass, or Fail. Add rule: if any subject is below 35, final result is Fail regardless of percentage. Also handle invalid input.
    Example Input: 82, 76, 91, 33, 88
    Example Output: Total = 370, Percentage = 74.0, Result = Fail (one subject below pass mark)
  5. Match based: Write a menu-driven calculator program using match-case for choices + - * / // % and default invalid choice. Handle division by zero safely.
    Example Input: a = 10, b = 0, op = /
    Example Output: Error: division by zero
  6. Operators based: Write a program to read two integers and print results of arithmetic, relational, logical, assignment update, bitwise, identity, and membership operator checks with proper labels. Include a short note where identity and equality may differ.
    Example Input: x = 5, y = 2
    Example Output: x+y=7, x//y=2, x&y=0, x==y=False, x is y=False, '5' in str(x)=True
