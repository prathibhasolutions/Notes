Section A: Multiple Choice Questions (10 x 1 = 10 Marks)

  1. Which keyword begins a conditional branch in Python? A) then B) if C) case D) switch
  2. Which keyword is used for an alternative branch when the if condition is false? A) elif B) alt C) else D) except
  3. In a multi-condition chain, which keyword checks another condition after if? A) elseif B) elif C) else if D) case
  4. What is the boolean value of an empty string in Python? A) True B) False C) None D) Error
  5. Which operator gives True only when both conditions are True? A) and B) or C) not D) is
  6. Which statement about match-case is correct in Python? A) It replaces all if-else in every case B) It matches patterns against a subject value C) It works only with numbers D) It does not support default case
  7. Which case pattern works as the default branch in match-case? A) else B) default C) _ D) any
  8. What is the result type of normal division of two integers? A) int B) float C) bool D) str
  9. Which operator checks value equality, not object identity? A) is B) == C) = D) !=
  10. What is the value of expression not True or False? A) True B) False C) Error D) None

Section B: Fill In The Blanks (10 x 1 = 10 Marks)

  1. The keyword used to check a condition is __________.
  2. The keyword used when the if condition is false is __________.
  3. The keyword used for an extra condition between if and else is __________.
  4. In match-case, the symbol used for any other value is __________.
  5. The keyword used to start pattern matching in Python is __________.
  6. The datatype obtained after converting 25 to text is __________.
  7. The boolean value of zero is __________.
  8. The operator used for floor division is __________.
  9. The operator used for exponentiation is __________.
  10. Negative index minus one in a string refers to the __________ character.

Section C: Programs (6 x 5 = 30 Marks)

Write clear and complete programs on the given topics. Use if-else and match where requested. Keep logic correct for edge cases and tricky values.

  1. Formula-based: Write a program to read length and breadth of a rectangle and print area, perimeter.
  2. If-else based: Write a program to read three numbers and print the greatest number. If all are equal, print that they are all equal.
  3. If-else based: Write a program to read a year and print whether it is a leap year or not using all conditions: divisible by 400 is leap year, divisible by 100 but not 400 is not leap year, divisible by 4 but not by 100 is leap year, otherwise not leap year.
  4. If-else based: Write a program to read marks in five subjects, calculate total and percentage, then print grade as Distinction, First Class, Second Class, Pass, or Fail. Also handle invalid input if any mark is less than 0 or greater than 100.
  5. Match based: Write a menu-driven calculator program using match-case for choices add, subtract, multiply, divide, and default invalid choice.
  6. Operators based: Write a program to read two integers and print results of arithmetic, relational, logical, assignment update, bitwise, identity, and membership operator checks with proper labels.
