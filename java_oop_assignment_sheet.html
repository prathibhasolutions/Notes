Java Object Oriented Programming Assignment Sheet
Topic-wise Programming Practice for Java Learners
Instructions: Solve each question using Java OOP concepts only. Write class design, Java source code, and a short explanation for every program. Use features like classes, objects, constructors, inheritance, interfaces, packages, and exception handling in Java.

Topic-wise Assignment Questions

1. Class and Object Basics

  1. Create a class Student with fields name, rollNo, and marks.
  2. Create two Student objects and display their details using a method.
  3. Write a Car class with attributes like brand, model, and speed.
  4. Create a Book class with title, author, and price, and print the details.

2. Constructors in Java

  1. Design a class Employee with a parameterized constructor.
  2. Create a Rectangle class using a constructor to initialize length and breadth.
  3. Write a class where each object stores a unique ID using constructor logic.
  4. Create a BankAccount class that initializes account number and balance in the constructor.

3. Methods and Behavior

  1. Create a Circle class with methods to compute area and circumference.
  2. Write a Calculator class with methods for add(), subtract(), multiply(), and divide().
  3. Build a Person class with methods like eat(), sleep(), and study().
  4. Create a LibraryBook class with methods to borrow and return the book.

4. Instance Variables and Static Members

  1. Create a class where a static variable counts the number of objects created.
  2. Use both instance and static variables in a class and explain the difference.
  3. Create a Department class with a static department name and instance-specific details.
  4. Write a program to show how a static method can be called without creating an object.

5. Encapsulation in Java

  1. Implement a Student class with private data members and getter/setter methods.
  2. Write a BankAccount class that restricts direct modification of the balance.
  3. Use private methods and public methods to show controlled access in a class.
  4. Demonstrate the use of access modifiers like public, private, and protected.

6. Inheritance

  1. Create a base class Animal and derived classes Dog and Cat.
  2. Write a Vehicle base class and derive Bike and Car.
  3. Make a Person parent class and Student child class.
  4. Implement a Shape base class with Rectangle and Circle derived classes.

7. Method Overriding and super()

  1. Create a base class Animal with a method sound() and override it in child classes.
  2. Use super() in a child constructor to call the parent constructor.
  3. Write a parent class Employee and child class Manager using method overriding.
  4. Build a program where a child class changes the behavior of a parent method.

8. Abstract Classes and Interfaces

  1. Create an abstract class Shape with abstract method area().
  2. Create an interface Printable with a method printDetails(), and implement it in a class.
  3. Write a program showing how one class can implement multiple interfaces.
  4. Build an example where an abstract class is used as a common base for multiple types.

9. Polymorphism in Java

  1. Create a Shape class hierarchy where different objects compute area differently.
  2. Write a method that accepts a parent type and works with multiple child objects.
  3. Demonstrate runtime polymorphism with method overriding.
  4. Use interface-based polymorphism to call different implementations through one reference type.

10. Packages and Import Statements

  1. Create a small package structure for a student and course system.
  2. Write classes in separate files and import them using package statements.
  3. Design a package-based OOP program where classes are separated by responsibility.
  4. Create a package-based Java program that uses public classes across different files.

11. Final, Static, and This Keywords

  1. Write a class using the final keyword for constants and final methods.
  2. Create a class that uses this to refer to the current object.
  3. Demonstrate the use of static variables and methods in a Java class.
  4. Write a program showing the difference between instance and class-level behavior.

12. Constructors, Overloading, and Method Overloading

  1. Write a Student class with overloaded constructors.
  2. Create a Calculator class with overloaded methods for addition.
  3. Overload a method for different parameter types in Java.
  4. Show how constructor overloading helps initialize objects in different ways.

13. Exception Handling in OOP

  1. Create a BankAccount class that throws an exception for invalid withdrawal.
  2. Use try, catch, and finally inside class methods.
  3. Write a Student class that validates marks and handles invalid input.
  4. Demonstrate custom exception handling in Java OOP.

14. Inner Classes and Nested Classes

  1. Create a class Student with a nested class Address.
  2. Use a member inner class and access its outer class members.
  3. Create a method-local inner class inside a class method.
  4. Explain how nested classes help organize related data in Java OOP.

15. Java OOP Extras for Beginners

  1. Create a class implementing the Comparable interface and compare objects.
  2. Use Java @Override annotation to show method overriding clearly.
  3. Write a program where one class contains another object as a field to show composition.
  4. Use the this keyword and constructor chaining to initialize a class correctly.

16. Mini Projects

  1. Create a Library Management System using classes for Book, Student, and Library.
  2. Build a Banking System with account creation, deposit, withdraw, and balance check.
  3. Design a Student Result Management System using Java classes and methods.
  4. Create a Hospital Management System for patient and appointment handling.

17. Advanced Practice Questions

  1. Design a Java class hierarchy for a restaurant ordering system.
  2. Create a shopping cart using classes like Product, CartItem, and Cart.
  3. Build a ticket booking system for trains or movies using Java OOP.
  4. Implement a simple quiz game using class-based design in Java.

18. Threads and Multithreading in Java

  1. Create a class that extends Thread and prints numbers from 1 to 10.
  2. Write a class that implements Runnable and runs it using a Thread object.
  3. Develop a program where two threads execute concurrently and print alternating values.
  4. Demonstrate thread synchronization using the synchronized keyword.
  5. Create a simple ticket-booking or counter system using multiple threads.
  6. Explain the difference between Thread and Runnable in Java.
Suggested Practice Plan: Start with classes, objects, constructors, and methods. Then move to encapsulation, inheritance, polymorphism, abstract classes, interfaces, exceptions, and finally mini projects.
