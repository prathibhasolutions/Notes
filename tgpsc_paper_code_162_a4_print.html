TGPSC Departmental Tests - Paper Code 162

Proficiency in Office Automation with Usage of Computers and Associated Software

Paper Code 162 for the Telangana Public Service Commission (TGPSC) Departmental Tests is a 1-hour computer proficiency and practical examination designed to test essential day-to-day office IT skills.

Syllabus - Core Modules

  • Operating System and Digital Workspace Management: Navigating Windows OS, using File Explorer, secure file organization, network/shared drives, basic printer and scanner handling, and digital security practices.
  • Word Processing (MS Word / Google Docs): Drafting official memos, letters, and meeting minutes; formatting documents; inserting tables/charts; mail merge; inter-department review and commenting.
  • Spreadsheet Skills (MS Excel / Google Sheets): Data entry, data cleaning, basic formulas (SUM, AVERAGE), sorting, filtering, conditional formatting, and basic charts.
  • Presentation Tools (MS PowerPoint): Creating professional slides, applying themes, basic animation/transitions, and inserting media/charts.
  • Internet Skills: Web browser usage, downloading designated files, and navigating official portals.

Exam Pattern and Details

Duration: 1 Hour

Mode: Online Computer Based Test (CBT)

Total Marks: 100

Minimum Passing Marks: 40

Print setting: A4 size, portrait orientation, default margins or minimum margins.
