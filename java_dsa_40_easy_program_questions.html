Java DSA Practice Sheet - 40 Program Questions

Java Collections + Arrays + Strings (1-20)

1) Two Sum (HashMap)

Given an integer array nums and target, return indices of two numbers such that they add up to target.

Example 1: nums = [2,7,11,15], target = 9 -> Output: [0,1] Example 2: nums = [3,2,4], target = 6 -> Output: [1,2]

2) Contains Duplicate (Set)

Return true if any value appears at least twice in the array, else false.

Example 1: nums = [1,2,3,1] -> true Example 2: nums = [1,2,3,4] -> false

3) Valid Anagram (Map or sorting)

Given two strings s and t, return true if t is an anagram of s.

Example 1: s = "anagram", t = "nagaram" -> true Example 2: s = "rat", t = "car" -> false

4) First Unique Character (HashMap)

Return the index of first non-repeating character. Return -1 if none.

Example 1: s = "leetcode" -> 0 Example 2: s = "aabb" -> -1

5) Intersection of Two Arrays (Set)

Return unique elements present in both arrays.

Example 1: nums1 = [1,2,2,1], nums2 = [2,2] -> [2] Example 2: nums1 = [4,9,5], nums2 = [9,4,9,8,4] -> [4,9]

6) Remove Duplicates from Sorted Array (Two pointers)

Modify sorted array in-place so each element appears only once. Return new length.

Example 1: nums = [1,1,2] -> length = 2, nums = [1,2,_] Example 2: nums = [0,0,1,1,1,2,2,3,3,4] -> length = 5

7) Merge Sorted Arrays (ArrayList or in-place)

Given nums1 and nums2 sorted, merge them into one sorted array.

Example 1: nums1=[1,2,3,0,0,0], m=3, nums2=[2,5,6], n=3 -> [1,2,2,3,5,6] Example 2: nums1=[1], m=1, nums2=[], n=0 -> [1]

8) Move Zeroes (Two pointers)

Move all 0 values to the end while keeping relative order of non-zero values.

Example 1: [0,1,0,3,12] -> [1,3,12,0,0] Example 2: [0] -> [0]

9) Missing Number (Set or math)

Array contains n distinct numbers in range [0,n]. Find the missing number.

Example 1: nums = [3,0,1] -> 2 Example 2: nums = [0,1] -> 2

10) Majority Element (Map or Boyer-Moore)

Find element appearing more than n/2 times.

Example 1: nums = [3,2,3] -> 3 Example 2: nums = [2,2,1,1,1,2,2] -> 2

11) Best Time to Buy and Sell Stock

Find max profit from one buy and one sell.

Example 1: prices = [7,1,5,3,6,4] -> 5 Example 2: prices = [7,6,4,3,1] -> 0

12) Running Sum of 1d Array

Return running sum where ans[i] = sum(nums[0..i]).

Example 1: [1,2,3,4] -> [1,3,6,10] Example 2: [1,1,1,1,1] -> [1,2,3,4,5]

13) Pivot Index

Return index where left sum equals right sum, else -1.

Example 1: [1,7,3,6,5,6] -> 6 index = 3 Example 2: [1,2,3] -> -1

14) Longest Common Prefix

Given array of strings, find longest common prefix.

Example 1: ["flower","flow","flight"] -> "fl" Example 2: ["dog","racecar","car"] -> ""

15) Valid Palindrome

Check if string is palindrome after removing non-alphanumeric and ignoring case.

Example 1: "A man, a plan, a canal: Panama" -> true Example 2: "race a car" -> false

16) Reverse String (Two pointers)

Reverse character array in-place.

Example 1: [h,e,l,l,o] -> [o,l,l,e,h] Example 2: [H,a,n,n,a,h] -> [h,a,n,n,a,H]

17) Roman to Integer

Convert Roman numeral string to integer.

Example 1: "III" -> 3 Example 2: "MCMXCIV" -> 1994

18) Length of Last Word

Return length of the last word in a string.

Example 1: s = "Hello World" -> 5 Example 2: s = " fly me to the moon " -> 4

19) Binary Search

Find target index in sorted array, otherwise return -1.

Example 1: nums=[-1,0,3,5,9,12], target=9 -> 4 Example 2: nums=[-1,0,3,5,9,12], target=2 -> -1

20) Search Insert Position

Return index if target found, else index where it should be inserted.

Example 1: nums=[1,3,5,6], target=5 -> 2 Example 2: nums=[1,3,5,6], target=2 -> 1

Stack, Queue, Linked List, Trees, Graphs, DP (21-40)

21) Valid Parentheses (Stack)

Check if brackets are valid and correctly nested.

Example 1: s = "()[]{}" -> true Example 2: s = "(]" -> false

22) Implement Queue Using Two Stacks

Design queue with push, pop, peek, empty using two stacks.

Example 1: push(1), push(2), peek() -> 1, pop() -> 1 Example 2: empty() after removing all -> true

23) Implement Stack Using Queues

Design stack with push, pop, top, empty using queue operations.

Example 1: push(1), push(2), top() -> 2 Example 2: pop() -> 2, empty() -> false

24) Reverse Linked List

Reverse singly linked list and return new head.

Example 1: 1->2->3->4->5 -> 5->4->3->2->1 Example 2: 1->2 -> 2->1

25) Middle of Linked List

Return middle node. If two middles, return second middle.

Example 1: 1->2->3->4->5 -> 3 Example 2: 1->2->3->4->5->6 -> 4

26) Linked List Cycle

Check if linked list has a cycle using fast and slow pointers.

Example 1: head=[3,2,0,-4], pos=1 -> true Example 2: head=[1,2], pos=-1 -> false

27) Merge Two Sorted Linked Lists

Merge and return one sorted linked list.

Example 1: [1,2,4] and [1,3,4] -> [1,1,2,3,4,4] Example 2: [] and [] -> []

28) Invert Binary Tree

Swap left and right child of all nodes.

Example 1: [4,2,7,1,3,6,9] -> [4,7,2,9,6,3,1] Example 2: [2,1,3] -> [2,3,1]

29) Maximum Depth of Binary Tree

Return number of levels in binary tree.

Example 1: [3,9,20,null,null,15,7] -> 3 Example 2: [1,null,2] -> 2

30) Same Tree

Given two trees p and q, check if structurally identical with same values.

Example 1: p=[1,2,3], q=[1,2,3] -> true Example 2: p=[1,2], q=[1,null,2] -> false

31) Symmetric Tree

Check if a binary tree is mirror of itself around center.

Example 1: [1,2,2,3,4,4,3] -> true Example 2: [1,2,2,null,3,null,3] -> false

32) Flood Fill (BFS/DFS)

Change color of connected region from start pixel to new color.

Example 1: image=[[1,1,1],[1,1,0],[1,0,1]], sr=1, sc=1, color=2 -> [[2,2,2],[2,2,0],[2,0,1]] Example 2: image=[[0,0,0],[0,0,0]], sr=0, sc=0, color=0 -> [[0,0,0],[0,0,0]]

33) Find if Path Exists in Graph

Given n nodes and edges, determine if path exists between source and destination.

Example 1: n=3, edges=[[0,1],[1,2],[2,0]], src=0, dest=2 -> true Example 2: n=6, edges=[[0,1],[0,2],[3,5],[5,4],[4,3]], src=0, dest=5 -> false

34) Climbing Stairs (DP)

You can climb 1 or 2 steps. Return number of distinct ways to reach n.

Example 1: n=2 -> 2 Example 2: n=3 -> 3

35) Min Cost Climbing Stairs (DP)

Given cost array, reach top with minimum total cost by climbing 1 or 2 steps.

Example 1: cost=[10,15,20] -> 15 Example 2: cost=[1,100,1,1,1,100,1,1,100,1] -> 6

36) House Robber (DP)

Max money without robbing two adjacent houses.

Example 1: nums=[1,2,3,1] -> 4 Example 2: nums=[2,7,9,3,1] -> 12

37) Coin Change (Easy DP intro)

Given coin values and amount, return minimum number of coins needed. Return -1 if impossible.

Example 1: coins=[1,2,5], amount=11 -> 3 (5+5+1) Example 2: coins=[2], amount=3 -> -1

38) Fibonacci Number

Return nth Fibonacci number where F(0)=0, F(1)=1.

Example 1: n=2 -> 1 Example 2: n=4 -> 3

39) Counting Bits

For each number i in range [0,n], return number of set bits in i.

Example 1: n=2 -> [0,1,1] Example 2: n=5 -> [0,1,1,2,1,2]

40) Number of 1 Bits

Given unsigned integer, return count of '1' bits in binary representation.

Example 1: n=11 (1011) -> 3 Example 2: n=128 (10000000) -> 1
